# `:set` / `:setlocal` `fileformat` isolation, `!`, and multi-query defects

**Category:** commands / options · **Area:** `vith/commands/options.py` · **Found at:** Round 18 full-project audit (2026-11-24, `v0.16.5`, hg rev `458:d2d313328875`) · **Fix status:** open

## Summary

`fileformat` (`ff`) is listed in `_LOCAL_SET_OPTION_NAMES`,[^src-local] but three places in `vith/commands/options.py` omit it from the structured value-option paths that handle `filetype` (`ft`) and `fileencoding` (`fenc`):

1. **`:setlocal ff=dos` mutates global `editor.fileformat`:** `_apply_set_token` falls through to `SET_COMMANDS[opt](editor, value)` without passing `is_local`,[^src-apply] and `set_fileformat` unconditionally assigns `editor.fileformat = fmt` in addition to `eb.fileformat = fmt`.[^src-ff] Subsequent newly created buffers inherit `'dos'` even though `:setlocal` was requested.
2. **`:set ff!` / `:set fileformat!` misclassified:** `_EXTRA_VALUE_OPTION_NAMES` contains `('filetype', 'ft', 'fileencoding', 'fenc')` without `'fileformat'` or `'ff'`.[^src-extra] Consequently, `:set ft!` reports `E474: Invalid argument: ft!`, whereas `:set ff!` reports `Unknown option: ff!`.
3. **Multi-token bare query (`:set ts ff`) clobbers `fileformat`:** When `value is None`, `int_info`, `list_info`, `filetype`, and `fileencoding` append to `queries` via `_append_set_query`, which `set_command_execute` joins with `'  '.join(queries)` at the end. Because `fileformat` falls through to `SET_COMMANDS['ff'](editor, None)` (which calls `editor.show_message('fileformat=unix')` directly), the trailing `editor.show_message('  '.join(queries))` immediately overwrites `fileformat=unix` with `'tabstop=8'`.[^src-exec]

## Evidence

Live probes against shipped `Editor` + `handle_command`:

| Command | Expected | Actual |
| :--- | :--- | :--- |
| `:setlocal ff=dos` | `eb.fileformat == 'dos'`, `editor.fileformat == 'unix'` | `editor.fileformat == 'dos'` |
| `:set ff!` | `'E474: Invalid argument: ff!'` | `'Unknown option: ff!'` |
| `:set ts ff` | `'tabstop=8  fileformat=unix'` | `'tabstop=8'` |

## Fix Direction

1. Add `'fileformat'` and `'ff'` to `_EXTRA_VALUE_OPTION_NAMES`.
2. Handle `opt in ('fileformat', 'ff')` explicitly in `_apply_set_token`: route `value is None` through `_append_set_query(editor, opt, queries)`, and pass `is_local=is_local` to `set_fileformat` (requiring an active buffer and leaving `editor.fileformat` untouched when `is_local=True`).
3. Add regression tests for `:setlocal ff=dos`, `:set ff!`, and `:set ts ff`.
