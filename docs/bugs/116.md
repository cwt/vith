# Missing `ZZ` / `ZQ` navigation-mode quit

**Category:** Vim semantics · **Area:** `vith/key_bindings.py`, `vith/commands/commands.py` · **Found at:** upstream triage 2026-11-09 (`prompt-toolkit/pyvim#122`, `#19`) · **Fix status:** open

## Summary

Normal-mode `ZZ` (write + quit) and `ZQ` (quit without saving) do nothing in `vith`.
Users must fall back to `:wq` / `:q!`.

## Evidence

* `vith/key_bindings.py:146-398`[^src-kb] registers `:`, `C-w`, `g t`, `x/X/s/r/~/e/E/$` — no `Z Z` or `Z Q` chord.
* Quit itself exists and is window-scoped: `quit()` in `vith/commands/commands.py:382-411`[^src-cmd] plus `write_and_quit()` at `:439-445`.
* Upstream report: `prompt-toolkit/pyvim#122` (`ZZ` in `.pyvimrc` never worked); `#19` (`:q`/`ZZ` confusion).

## Impact

* Vim muscle-memory break; low data risk (`:wq` works), but high papercut frequency.

## Fix direction

* Add `Z Z` → `write_and_quit(active buffer)` and `Z Q` → `quit(force=True)` under `vi_navigation_mode`, honoring unsaved-changes guards in [067](067.md).
* Add regression tests for last-window exit vs multi-window close.
