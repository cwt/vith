# `DocumentWordsCompleter` regex (`\w+`) strips Thai/Lao combining marks (`GC=Mn`) and fails to complete Thai words

**Category:** wrong logic / Thai support · **Area:** `vith/completion.py` (`DocumentWordsCompleter`) · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

`DocumentWordsCompleter` indexes buffer words using `_WORD_RE = re.compile(r'\w+')`[^src-comp]. In Python's standard `re` module, `\w` matches Unicode general categories `L*` (letters), `Nl`/`No`/`Nd` (numbers), and `_`, but **does not match `GC=Mn` (Mark, Nonspacing)**. All Thai and Lao above/below vowels, tone marks, and diacritics (`U+0E31`, `U+0E34..U+0E3A`, `U+0E47..U+0E4E`, `U+0EB1`, `U+0EB4..U+0EBC`, `U+0EC7..U+0ECE`) have `GC=Mn`.

Meanwhile, `document.get_word_before_cursor()` (`vith/completion.py:55`)[^src-comp] calls `Document.find_start_of_previous_word`, which is patched by `vith/thai.py:678-689`[^src-thai] to return the full Thai syllable/cluster including its combining marks. As a result:

1. `_WORD_RE.findall(doc.text)` splits every Thai/Lao word at each combining mark and strips all combining marks from the indexed completion candidates.
2. When the user types a Thai prefix containing a combining mark (e.g. `"ที่"`), `word_before_cursor` is `"ที่"`, which never matches any token in `_other_words_sorted`.
3. When the user types a Thai prefix without a combining mark before the cursor (e.g. `"ให"` for `"ผู้ใหญ่"`), the completer offers the corrupted token `"ใหญ"` with its trailing tone mark `'◌่'` (`U+0E48`) stripped off.

## Evidence

* [`vith/completion.py:48-84`](../../vith/completion.py)[^src-comp]:
  ```python
  class DocumentWordsCompleter(Completer):
      _WORD_RE = re.compile(r'\w+')
      ...
      def get_completions(self, document, complete_event):
          word_before_cursor = document.get_word_before_cursor()
  ```
* **Live probe**:
  ```python
  >>> import re
  >>> re.findall(r'\w+', 'ที่ดิน น้ำ ผู้ใหญ่')
  ['ท', 'ด', 'น', 'น', 'ำ', 'ผ', 'ใหญ']
  ```
  * On `Document("ที่ดิน น้ำ ผู้ใหญ่\nที่", cursor_position=21)`:
    `word_before_cursor == 'ที่'`, completions returned: `[]`.
  * On `Document("ที่ดิน น้ำ ผู้ใหญ่\nให", cursor_position=20)`:
    `word_before_cursor == 'ให'`, completions returned: `['ใหญ']` (missing `'◌่'`).

## Impact

In-buffer Tab word completion is broken for Thai, Lao, and any script using combining marks (`GC=Mn` / `GC=Mc`).

## Fix direction

Include Unicode combining marks (`\u0e31-\u0e3a\u0e47-\u0e4e\u0eb1-\u0ebc\u0ec7-\u0ece` or a combining-mark suffix class) in `_WORD_RE`, and for Thai/Lao runs either segment by whitespace/punctuation or reuse `thai.thai_word_starts` so indexed words align with `document.get_word_before_cursor()`.
