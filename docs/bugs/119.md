# `Ctrl-[` does not exit insert mode

**Category:** Vim semantics · **Area:** `vith/key_bindings.py` · **Found at:** upstream triage 2026-11-09 (`prompt-toolkit/pyvim#134`) · **Fix status:** open

## Summary

In Vim, `Ctrl-[` is equivalent to `Esc`. In `vith` document buffers it does nothing.

## Evidence

* `create_key_bindings()` in `vith/key_bindings.py:146-398`[^src-kb] binds `escape` only for `has_focus(editor.command_buffer)` (`:232-242`); document insert-mode exit relies on `prompt_toolkit` defaults, which do not map `c-[`.
* No `c-[` (or `c-c`) binding exists for document buffers.

## Impact

* Terminal / Vim muscle-memory break; `Esc` is harder to reach on many layouts.

## Fix direction

* Add `@kb.add('c-[', filter=vi_insert_mode)` (plus `c-c` for parity) mapping to `InputMode.NAVIGATION`, mirroring `prompt_toolkit` Vi behavior.
* Add key-binding regression test.
