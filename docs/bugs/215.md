# `FiletypeTabstops.setdefault` allows `None` values into `dict[str, int]`

**Category:** editor / filetype tabstops · **Area:** `vith/editor.py` · **Found at:** Round 18 full-project audit (2026-11-24, `v0.16.5`, hg rev `458:d2d313328875`) · **Fix status:** open

## Summary

Finding [201](201.md) tightened `FiletypeTabstops.__setitem__` and `setdefault` to enforce `int >= 1` (non-`bool`), but `FiletypeTabstops.setdefault` explicitly special-cases `default is None` with `# type: ignore[arg-type]` and delegates `super().setdefault(canonical, None)`:[^src]

```python
def setdefault(self, key: str, default: Any = None) -> Any:
    canonical = _canonical_filetype(str(key).lower())
    if default is None:
        return super().setdefault(canonical, None)  # inserts None when missing!
```

Calling `ft.setdefault('python')` on a missing filetype inserts `'python': None` into `FiletypeTabstops`. Thereafter, `editor.get_filetype_tabstop('python')` returns `None` (`super().__contains__('python')` is `True`, so `super().__getitem__('python')` returns `None`), `eb.tabstop` returns `None`, and callers such as `int(eb.tabstop)` raise `TypeError`.

## Evidence

Live probe:

```python
ft = FiletypeTabstops()
res = ft.setdefault("python")
# res == None, dict(ft) == {'python': None}
```

## Fix Direction

1. In `FiletypeTabstops.setdefault`, if `canonical` is already present (`super().__contains__(canonical)`), return `super().__getitem__(canonical)` immediately; otherwise validate `default` with the exact same `isinstance(default, bool) or not isinstance(default, int) or default < 1` check (rejecting `None` with `ValueError`) before inserting.
2. Add a regression test asserting `ft.setdefault('missing')` raises `ValueError` without mutating `ft`, while `ft.setdefault('py')` on `FiletypeTabstops({'python': 4})` returns `4`.
