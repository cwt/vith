# Startup and I/O robustness: single-level `mkdir`, bare `assert` on `-p -o`, latin-1 write failure, unknown-location indistinguishability

**Category:** wrong logic / robustness (grouped lows) · **Area:** `vith/editor.py`, `vith/editor_buffer.py`, `vith/entry_points/run_vith.py`, `vith/io/backends.py` · **Found at:** deep review, hg rev 87de3a3 (2026-11-08)

## Summary

Four small defects, grouped as in [054](054.md):

1. `Editor.__init__` uses `os.mkdir(config_directory)` (single level). A nested config path (`/tmp/a/b/c`) raises `FileNotFoundError`; concurrent launches race.
2. `vith -p -o` (or `-p -O`, `-o -O`) reaches `assert in_tab_pages + hsplit + vsplit <= 1` in `load_initial_files` → bare `AssertionError`, no usage message.
3. `_auto_decode` falls back to latin-1 and records it as `self.encoding`. Typing Thai into that buffer then `:w` raises `UnicodeEncodeError` → “cannot write”, no utf-8 fallback.
4. `_read` returns `''` both for “file does not exist” (legit new file) and “unknown location scheme” (after showing a message but still creating a buffer with that location). The subsequent `:w` then fails with “Unknown location” — a two-step confusing UX.

## Evidence

* [`vith/editor.py:84-85`](../../vith/editor.py)[^src-ed] — `os.mkdir`.
* [`vith/editor.py:159`](../../vith/editor.py) + [`vith/entry_points/run_vith.py:31-33`](../../vith/entry_points/run_vith.py) — unguarded `assert`.
* [`vith/io/backends.py:159-169`](../../vith/io/backends.py)[^src-io] + [`vith/editor_buffer.py:109-143`](../../vith/editor_buffer.py) — decode/encode round-trip.
* [`vith/editor_buffer.py:142-143`](../../vith/editor_buffer.py) — `show_message('Cannot read')` then `return ''`.

## Impact

Each is low-severity alone; together they are the remaining “first-run / save-path” paper cuts.

## Fix direction

`os.makedirs(..., exist_ok=True)`; validate `-p/-o/-O` mutual exclusion in `run()` with a friendly error; on `UnicodeEncodeError` at write time, offer utf-8 (or update `self.encoding` with warning); distinguish “new file” (`is_new=True`, silent) from “unknown backend” (refuse to create a buffer or mark it read-only).
