# Cold-text benchmark measures its own copy (008 regression)

**Category:** benchmark fidelity / duplicated implementation · **Area:** `tools/bench_quez_cold_text.py` · **Found at:** Round 5 audit, 2026-11-09, hg rev 256 · **Fix status:** open

## Summary

[008](008.md) fixed `tools/bench_plans.py` to import shipped modules instead of validating duplicated re-implementations. Its sibling tool was never updated:

| | `bench_quez_cold_text.py` (measured) | `vith/cold_text.py` (shipped) |
| :-- | :-- | :-- |
| Class | `ColdTextStore` (`:129`) | `ColdTextStack`, `ColdTextBuffer` |
| Push | `push(text) -> None` | `push(text, cursor_position, text_version)` |
| Pop | `pop() -> str` | `pop() -> (text, cursor_position, text_version)` |
| Extras | `stats` passthrough | `update_top_cursor`, `undo`/`redo`, `cold_text_stats` |
| Imports | `quez` only | — **never imported** |

The docstring still says *"This is the shape a **future** vith integration would use"* (`:4`, `:133`) and the closing notes say *"A production design may store diffs"*, even though `CHANGELOG` 0.10.0 shipped compressed cold-text undo/redo.

Probe: `python tools/bench_quez_cold_text.py --sizes-mb 0.05 --snapshots 3` runs cleanly and prints numbers produced entirely by the local class.

## Evidence

* [`tools/bench_quez_cold_text.py:129-149`](../../tools/bench_quez_cold_text.py)[^src-bench] — local `ColdTextStore`; no `vith.cold_text` import anywhere in the file.
* [`tools/bench_quez_cold_text.py:4`](../../tools/bench_quez_cold_text.py)[^src-bench] — "**Demo/benchmark** … not for the active editor buffer" / "future vith integration".
* [`vith/cold_text.py:42-47`](../../vith/cold_text.py)[^src-impl] — `__all__ = ('ColdTextBuffer', 'ColdTextStack', 'format_cold_text_stats', 'make_cold_text_compressor')`.
* [`tools/bench_quez_cold_text.py:224`](../../tools/bench_quez_cold_text.py)[^src-bench] — `measure_ns()` returns `median(ns)/1_000_000` (milliseconds) despite its name.
* [`tools/bench_quez_cold_text.py:165-188`](../../tools/bench_quez_cold_text.py)[^src-bench] — `build_source_text()` truncates with `[:target_bytes]`; `build_thai_text()` does not, so the `req MB` / `utf8 MB` columns disagree (observed `thai 0.1 req / 0.05 utf8 / 0.09 str MB`).

## Impact

Every figure printed describes a parallel implementation that can drift from shipped behaviour without any test noticing — the exact defect class [008](008.md) closed for `bench_plans.py`. The misleading `measure_ns` name and the untruncated Thai fixture further reduce trust in the output.

## Fix

In `tools/bench_quez_cold_text.py`:
- Updated `ColdTextStore` to adapt and drive shipped `vith.cold_text.ColdTextStack`.
- Renamed `measure_ns` -> `measure_ms` to accurately reflect millisecond return values.
- Truncated `build_thai_text` to `target_bytes` matching `build_source_text`.
- Refreshed docstrings to reflect shipped cold-text implementation.
