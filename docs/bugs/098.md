# Re-entrant early-return leaks the autowrap tag

**Category:** state leak / cleanup bypass · **Area:** `vith/thai.py` (`_install_renderer_patch`) · **Found at:** Round 5 audit, 2026-11-09, hg rev 256 · **Fix status:** open

## Summary

Inside `_wrapped_output_screen_diff`:

1. Tags are injected and recorded at `:649-672`: `zw_row[target_col] = old_esc + _AUTOWRAP_ARM_TAG` and `saved_escapes.append(...)`.
2. `:674` returns safely when `saved_escapes` is empty.
3. `:677-681` handles a nested `run_in_terminal` / already-swapped output:

```python
if getattr(output, "_vith_write_swap_active", False):
    return orig_diff(*args, **kwargs)   # bypasses the finally at :707-717
```

At this point `saved_escapes` **is** non-empty (otherwise `:674` would have returned). The `finally` at `:707-717` is the *only* code that restores/pops the injected `zw_row[target_col]` entries, so `\x00_VITH_THAI_AUTOWRAP_\x00` survives in `screen.zero_width_escapes`, which prompt_toolkit carries into the next frame as `previous_screen`.

## Evidence

* [`vith/thai.py:649-672`](../../vith/thai.py)[^src-thai] — tag injection and `saved_escapes` population.
* [`vith/thai.py:674-681`](../../vith/thai.py)[^src-thai] — the two early returns; only the first is safe.
* [`vith/thai.py:705-717`](../../vith/thai.py)[^src-thai] — `try/finally` with the cleanup loop; unreachable from `:681`.
* [`vith/thai.py:688-693`](../../vith/thai.py)[^src-thai] — the tag is only converted to `\x1b[?7h` by the swapped `_wrapped_write_raw`; in the re-entrant path the outer wrapper owns the swap.

## Impact

Rare (requires nested `run_in_terminal` while `DECAWM`-armed output is active), but leaves a stray control marker in the screen state that can be emitted as literal bytes or poison the following frame's row.

## Fix

In `_wrapped_output_screen_diff` ([`vith/thai.py`](../../vith/thai.py)):
- Wrapped all code following escape tag injection in an outer `try/finally` block that restores `screen.zero_width_escapes` on every exit path, including re-entrant `_vith_write_swap_active` calls.
- Added regression test `test_reentrant_output_screen_diff_restores_escapes` in [`tests/test_thai.py`](../../tests/test_thai.py).
