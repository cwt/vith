# `_resolve_hook_path` directory collision and `config_path=None` `custom_dir` drop

**Category:** configuration / hooks · **Area:** `vith/rc_file.py` · **Found at:** Round 18 full-project audit (2026-11-24, `v0.16.5`, hg rev `458:d2d313328875`) · **Fix status:** fixed (hg rev 477)

## Summary

`_resolve_hook_path(hook_name, config_path=None, custom_dir=None)` has two path-resolution flaws:[^src]

1. **Directory collision (`os.path.exists` instead of `os.path.isfile`):** When a hook is configured by stem (e.g. `enabled = ["myhook"]`) and the user launches `vith` from a project directory containing a subdirectory `./myhook/`, `os.path.exists(expanded)` returns `True` for the directory, returning `/cwd/myhook` instead of `<config_dir>/hooks/myhook.py` and causing `run_hook_file` to fail with `IsADirectoryError` (`find_config_file` has the same `os.path.exists` check).
2. **`custom_dir` ignored when `config_path is None`:** `if custom_dir:` is nested inside `if config_path:`, so calling `apply_toml_config(editor, data)` programmatically without `config_path` silently drops `[hooks] directory = "/abs/or/tilde/hooks"`.

## Evidence

Live probes of `_resolve_hook_path`:

* With `./myhook/` directory in CWD and `custom_hooks/myhook.py` present: `_resolve_hook_path("myhook", config_path=".../config.toml", custom_dir="custom_hooks")` returns `"/tmp/.../myhook"` (`os.path.isdir(...) == True`).
* With `config_path=None` and `custom_dir="/tmp/.../custom_hooks"` containing `other.py`: `_resolve_hook_path("other.py", config_path=None, custom_dir=hooks_dir)` returns `None`.

## Fix Direction

1. Replace `os.path.exists` with `os.path.isfile` across `_resolve_hook_path`, `run_hook_file`, and `find_config_file` (removing the duplicate `os.path.isabs` branch in `_resolve_hook_path`).
2. Resolve `custom_dir` even when `config_path is None` (treating relative `custom_dir` relative to `config_dir` when `config_path` is given, or directly via `expand_location(custom_dir)` when absolute or `config_path is None`).
3. Add regression tests for directory-name collisions and `apply_toml_config` with `hooks.directory` and `config_path=None`.
