# `:cd` without an argument raises uncaught `TypeError` and skips `os.path.expanduser`

**Category:** crash / wrong logic · **Area:** `vith/commands/commands.py` (`cd`) · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

`cd(editor, location)` is registered via `@location_cmd('cd')`[^src-cmd]. When the user executes `:cd` with no argument (which in Vim changes to the user's home directory `~`), `COMMAND_GRAMMAR` (`vith/commands/grammar.py:45`)[^src-gram] matches the bare-command branch `(?P<command>[^\s!]+)` where `variables.get('location')` is `None`.

Inside `cd(editor, location)` (`vith/commands/commands.py:428-435`)[^src-cmd]:
1. `os.chdir(None)` is called and raises `TypeError: chdir: path should be string, bytes or os.PathLike, not NoneType`, which is not caught by `except OSError as e:`.
2. Even when an argument such as `:cd ~` or `:cd ~/Projects` is supplied, `os.chdir(location)` does not call `os.path.expanduser(location)`, failing with `FileNotFoundError: [Errno 2] No such file or directory: '~'`.

## Evidence

* [`vith/commands/commands.py:428-435`](../../vith/commands/commands.py)[^src-cmd]:
  ```python
  @location_cmd('cd')
  def cd(editor, location):
      "Change backend directory."
      try:
          os.chdir(location)
      except OSError as e:
          editor.show_message(f'{e}')
  ```
* **Live probe**:
  ```python
  >>> from vith.commands.handler import handle_command
  >>> handle_command(editor, ':cd')
  TypeError: chdir: path should be string, bytes or os.PathLike, not NoneType
  ```

## Impact

Typing `:cd` without arguments crashes the editor; typing `:cd ~` or `:cd ~/...` fails instead of changing to the home directory.

## Fix direction

Default `location = location or '~'` and expand `~` before calling `os.chdir`:

```python
@location_cmd('cd')
def cd(editor, location):
    "Change working directory."
    target = os.path.expanduser(location or '~')
    try:
        os.chdir(target)
    except OSError as e:
        editor.show_message(f'{e}')
```
