# `:s` flags grammar gaps and `:0,1s` E19

**Category:** wrong grammar (stem: 048/055 substitute family) · **Area:** `vith/commands/grammar.py:22`, `vith/commands/commands.py` (`substitute` range math) · **Found at:** stem audit, hg rev 269 · **Fixed at:** hg rev 271

## Summary (pre-fix probes)

* `:s/Violet/Rose//g` — replacement='' with flags → “Not an editor command” (generic branch ate the whole string);
* `:s/Violet/Rose/gg`, `gI`, `:s/x/y//gI` — same rejection;
* `:s/x/y//g`/`:$s/...`/`:%s/...` — ranges beyond `\d+,\d+` still unsupported (documented limitation, unchanged);
* `:0,1s/a/b/` — `E19: No such line in current buffer` although Vim maps row 0 onto the first line.

## Fix

* grammar tail rebuilt: `(?P<flags> ( / \w* )* )?` — accepts `/g`, `/`, `//g`, `/gg`, `/gI` (the handler already strips slashes);
* `substitute` range math clamps `range_start`/`range_end` to ≥ 0 (row 0 == row 1).

> Note: `:%s`, `:$s`, `:'<,'>` style ranges remain unsupported (pre-existing; the same grammar class as the round-2 004 range work) — filed as a future improvement, not a regression.
