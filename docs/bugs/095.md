# `:q` blocked by a dirty buffer in another window

**Category:** wrong logic / Vim semantics · **Area:** `vith/commands/commands.py` · **Found at:** Round 5 audit, 2026-11-09, hg rev 256 · **Fix status:** open

## Summary

```python
ebs = window_arrangement.editor_buffers                      # commands.py:381
if not force and any(eb.has_unsaved_changes for eb in ebs):  # :384  <-- ALL buffers
    editor.show_message(_NO_WRITE_SINCE_LAST_CHANGE_TEXT)
elif not all_ and (len(tab_pages) > 1 or active_tab.window_count() > 1):
    window_arrangement.close_window()                        # :393  never reached
```

The dirty guard runs **before** the window-close branch, so any modified buffer — including one that is hidden, or merely visible in a *different* window — vetoes closing the current window.

Probe (2 windows, active buffer clean, a hidden buffer dirty):

```text
hidden dirty: True  hidden visible: False  windows: 2
:q -> exited=False  msg='No write since last change (add ! to override)'  windows after=2
```

## Evidence

* [`vith/commands/commands.py:381-393`](../../vith/commands/commands.py)[^src-cmd] — `ebs` is the full buffer list; the guard precedes `close_window()`.
* [`vith/commands/commands.py:387-389`](../../vith/commands/commands.py)[^src-cmd] — inline comment: *"hidden buffers do not block it any more (docs/bugs/067.md)"* — contradicted by `:384`.
* [`docs/bugs/067.md:90`](067.md) — fix record: *"`:q` now closes the current window/tab … hidden buffers no longer block it"*.
* [`tests/test_quit_and_goto.py:16-59`](../../tests/test_quit_and_goto.py)[^src-test] — covers **clean** hidden buffers (`test_q_exits_despite_hidden_clean_buffers`) and a **dirty active** buffer (`test_q_blocks_on_dirty_buffers`); no dirty-hidden / dirty-other-window case.

## Impact

Daily-driver friction: after a split, `:q` appears not to work when any buffer anywhere has unsaved edits. In Vim, `:q` closes the current window; a modified buffer still shown in another window is irrelevant (`:qa` / `:quitall` is what warns).

## Fix direction

For `:q` (not `all_`), guard only the **current window's** buffer (`window_arrangement.active_editor_buffer`) — or skip the guard entirely when the close is not the last window. Keep the all-buffers scan for `:qa`/`:wqa`. Add regression tests for dirty-hidden and dirty-other-window cases.
