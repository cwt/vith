# Gate decay disarms the sanitizer while non-text renderables show Thai

**Category:** missed coverage (stem: 072 decay / 002 sanitizer) · **Area:** `vith/thai.py` (`reset_thai_text_gate_if_all_buffers_ascii`) · **Found at:** stem audit, hg rev 269 · **Fixed at:** hg rev 270

## Summary (machine-probed paths, all buffers ASCII)

| # | Flow | Thai rendered where |
|---|---|---|
| 1 | `:b ดำหลัง` → `E94: ... ดำหลัง` | `MessageToolbarBar` every frame |
| 2 | `:e <Thai-named nonexistent file>` → status bar | `WindowStatusBar` renders `location` (SARA `ำ` included) inline |
| 3 | Open Thai-named file + type `:b ` on an ASCII buffer overlay | `BufferListOverlay` tokens |

Emission-divergence demonstration: with a SARA-AM cell whose neighbor differs,
patched diff rewrites both cells (`'กำ'`), decayed diff one (`'ำ'`) — the
differential-generation guarantee is off for these windows. Whether that is
*visually* corrupt depends on the terminal → artifact **LIKELY** (low), the
coverage miss itself **CONFIRMED**.

## Fix

`reset_thai_text_gate_if_all_buffers_ascii` additionally holds the gate when any
`editor_buffer.location` is non-ASCII and when `editor.message` is non-ASCII.
Tests: `tests/test_thai.py::test_gate_decay_respects_thai_statusbar_and_names`
(location banner, message banner, clean decay).
