# Uncaught `ValueError` on Unicode `isdigit()` characters in preview and `:tabmove`

**Category:** command preview / tab management · **Area:** `vith/commands/preview.py`, `vith/window_arrangement.py` · **Found at:** Round 18 full-project audit (2026-11-24, `v0.16.5`, hg rev `458:d2d313328875`) · **Fix status:** open

## Summary

In Python, `str.isdigit()` returns `True` for Unicode `Numeric_Type=Digit` characters that `int(..., 10)` rejects — notably Latin-1 superscripts `'²'` (`U+00B2`), `'³'` (`U+00B3`), `'¹'` (`U+00B9`), and circled digits (`'①'`). Two call sites gate `int(...)` solely on `.isdigit()` without `isascii()` or `try/except ValueError`:

1. **`CommandPreviewer._preview_int_value`:** `if raw_value and raw_value.isdigit() and int(raw_value) >= minimum:` runs on every keystroke in the `:` command line, crashing with an uncaught `ValueError` when typing `:set ts=²`.[^src-preview]
2. **`WindowArrangement.move_tab`:** `elif rest.isdigit(): delta = int(rest)` and `elif arg.isdigit(): n = int(arg)` raise `ValueError` on `:tabm ²` or `:tabm +²` instead of reporting `E474: Invalid argument`.[^src-tab]

Note that `vith/commands/global_cmd.py:154` already guards this correctly with `stripped_dest.isascii() and stripped_dest.isdigit()`.

## Evidence

Live probe against shipped `Editor`:

* `ed.previewer.preview("set ts=\u00b2")` → raises `ValueError: invalid literal for int() with base 10: '²'`.
* `ed.window_arrangement.move_tab("\u00b2")` (with 2 tabs open) → raises `ValueError: invalid literal for int() with base 10: '²'`.

## Fix Direction

1. Require `s.isascii() and s.isdigit()` (or wrap `int(s)` in `try ... except ValueError`) in `CommandPreviewer._preview_int_value` and `WindowArrangement.move_tab` (and check other `.isdigit()` sites such as `_go_to_line` in `vith/commands/handler.py:232`).
2. Add regression tests feeding `'set ts=²'` to `CommandPreviewer.preview` and `'²'` / `'+²'` to `:tabm`.
