# `:[range]normal` skips rows after line-count-reducing keys

**Category:** wrong logic / range replay · **Area:** `vith/commands/commands.py` (`_execute_normal_on_rows`, `normal_command`) · **Found at:** Round 8 full re-audit, 2026-11-19, hg rev 358 (`ff583fcf26ba`) · **Fix status:** open

## Summary

`normal_command()` passes a fixed list of original row indices to
`_execute_normal_on_rows()` ([`:3201-3212`](../../vith/commands/commands.py#L3201-L3212)).
The replay loop does:

```python
target_row = raw_row + line_offset if track_line_delta else raw_row
...
if target_row < 0 or target_row >= len(doc.lines):
    continue
```

([`:3140-3145`](../../vith/commands/commands.py#L3140-L3145)).
`track_line_delta` is only enabled by the `:g/.../norm` path
([`:3028-3037`](../../vith/commands/commands.py#L3028-L3037)); a plain
`:[range]norm` therefore uses the original row numbers and silently skips any
row that no longer exists after a deletion/join.

Vim addresses the range by current line number and **clamps** the final
address to the last line. For a line-deleting normal command this means the
remaining last line is still processed.

## Evidence

Input `1\n2\n3\n4\n5`:

| Command | Vim result | Vith result |
| :--- | :--- | :--- |
| `:1,3normal dd` | `2\n4` | `2\n4` (same) |
| `:1,4normal dd` | `2` | `2\n4` (row 3 skipped) |
| `:1,5normal dd` | empty buffer (E749) | `2\n4` (rows 3–4 skipped) |

For insertion-style keys (`:%normal A!`, `:1,3normal oX`) the fixed row
indices match Vim, so the divergence is specific to line-count reduction.

## Impact

* `:[range]norm dd` / `:%norm J` / `:g`-less batch edits silently leave lines
  behind.
* Users cannot rely on `:[range]norm` to process every addressed line when the
  key sequence changes the line count.

## Fix direction

1. Clamp `target_row` to `len(doc.lines) - 1` for range playback (matching
   Vim's final-address clamp), or reuse the `line_offset` delta tracking used
   by `:g/.../norm`.
2. Keep the current `continue` only for genuinely invalid negative rows
   (empty buffer).
3. Add tests for `:1,4normal dd`, `:1,5normal dd`, `:%normal J`, and
   `:%normal oX`.
