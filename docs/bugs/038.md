# `_delete_cell_clusters` raises `UnboundLocalError` on `X` at column 0 or `x` on an empty line

**Category:** crash · **Area:** `vith/key_bindings.py` (`_delete_cell_clusters`) · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

The shared helper `_delete_cell_clusters(event, backward)` (extracted when deduplicating `x` and `X` in [029](029.md)) binds `text` only inside `if span > 0:`, but unconditionally passes `text` to `event.app.clipboard.set_text(text)` outside the conditional[^src-kb]. Pressing `X` at the beginning of any line (`col == 0`) or pressing `x` on an empty line (`line == ""`) leaves `span == 0` and crashes with `UnboundLocalError`.

## Evidence

* [`vith/key_bindings.py:205-220`](../../vith/key_bindings.py)[^src-kb]:
  ```python
  def _delete_cell_clusters(event, backward):
      "Delete `event.arg` cell clusters before/after the cursor on the current line."
      buff = event.current_buffer
      doc = buff.document
      line = doc.current_line
      col = doc.cursor_position_col
      if backward:
          span = col - prev_cell_offset(line, col, event.arg)
          if span > 0:
              text = buff.delete_before_cursor(count=span)
      else:
          span = next_cell_offset(line, col, event.arg) - col
          if span > 0:
              text = buff.delete(count=span)
      event.app.clipboard.set_text(text)
  ```
* When `backward=True` and `col == 0`, `prev_cell_offset(line, 0, event.arg)` returns `0`, so `span == 0`.
* When `backward=False` and `line == ""` (`col == 0`), `next_cell_offset("", 0, event.arg)` returns `0`, so `span == 0`.
* In both cases, `event.app.clipboard.set_text(text)` raises:
  `UnboundLocalError: cannot access local variable 'text' where it is not associated with a value`.

## Impact

Pressing `X` at column 0 or `x` on an empty line in Normal mode immediately crashes the editor.

## Fix direction

Only update the clipboard when `span > 0` (matching `prompt_toolkit/key_binding/bindings/vi.py:929-946`, which leaves the clipboard untouched when nothing was deleted):

```python
span = (
    col - prev_cell_offset(line, col, event.arg)
    if backward
    else next_cell_offset(line, col, event.arg) - col
)
if span > 0:
    text = (
        buff.delete_before_cursor(count=span)
        if backward
        else buff.delete(count=span)
    )
    event.app.clipboard.set_text(text)
```
