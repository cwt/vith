# Per-filetype standard tab stops and buffer-local tabstop options

**Category:** feature / generalization · **Area:** `vith/editor.py`, `vith/editor_buffer.py`, `vith/layout.py`, `vith/key_bindings.py`, `vith/commands/` · **Found at:** user request to generalize tab stops per filetype with standard defaults (2026-11-12) · **Fix status:** fixed

## Summary

`vith` defaulted to Vim's standard `tabstop = 8` for generic text, but lacked per-filetype defaults or buffer-local options. Different programming and markup filetypes follow well-established tab stop and indentation standards (e.g. 2 spaces for JavaScript, TypeScript, HTML, CSS, JSON, YAML, Bash, Markdown; 4 spaces for Python, Rust, Go, C, C++, Java, PHP, Zig, Swift; 8 spaces for Makefiles and generic text). Furthermore, `:set tabstop` was purely global, without `:setlocal tabstop` or buffer-local resolution.

## Evidence

* Previously, `self.tabstop` existed only on `Editor` (`vith/editor.py:87`).
* `TabsProcessor` in `vith/layout.py` evaluated only `self.editor.tabstop`.
* Indentation bindings (`<Tab>`, `<C-t>`, `>>`, `<<` in `vith/key_bindings.py`) read only `editor.tabstop`.
* `:set filetype=...` updated syntax highlighting but had no effect on tab stops.
* No `:setlocal tabstop=...` or `:setl ts=...` existed for buffer-local customization.

## Impact

* Opening a Python or JavaScript file under Vim's standard `tabstop = 8` displayed tabs wider than standard project conventions unless the user changed the global `:set ts=...`.
* Changing `:set ts=4` for Python affected all buffers globally, including Makefiles and tab-aligned text files.

## Fix

1. **Per-Filetype Tab Stop Mapping (`vith/editor.py`)**:
   * Introduced `DEFAULT_FILETYPE_TABSTOPS` with standard conventions:
     * 2 spaces: `javascript`, `typescript`, `html`, `css`, `scss`, `sass`, `less`, `json`, `yaml`, `ruby`, `lua`, `bash`, `markdown`, `xml`, `graphql`, `vue`, `svelte`.
     * 4 spaces: `python`, `rust`, `go`, `c`, `cpp`, `csharp`, `java`, `kotlin`, `php`, `zig`, `swift`, `scala`, `perl`, `sql`.
     * 8 spaces: `make`, `gitcommit`.
   * Created `FiletypeTabstops(dict[str, int])` with automatic canonical alias normalization via `_canonical_filetype(key)`: querying or setting any alias (e.g. `'py'` vs `'python'`, `'js'` vs `'javascript'`, `'ts'` vs `'typescript'`, `'c++'` vs `'cpp'`) synchronizes with the canonical name.
   * Added `editor.filetype_tabstops` property and `editor.get_filetype_tabstop(filetype)` helper.
2. **Buffer-Local `filetype` and `tabstop` (`vith/editor_buffer.py`)**:
   * Added `EditorBuffer.filetype` property (resolving `:set ft` override, filename-based Pygments lexer alias, or shebang/content sniff).
   * Added `EditorBuffer.tabstop` property with 3-tier resolution:
     1. Buffer-local override (`self._tabstop_override`), e.g. from `:setlocal tabstop=N` or `:set tabstop=N`.
     2. Filetype-specific setting from `editor.filetype_tabstops` matching buffer's `filetype`.
     3. Global editor default (`editor.tabstop`, default 8).
   * Setter `EditorBuffer.tabstop = value` for buffer-local configuration.
3. **Display and Indentation Integration**:
   * Updated `vith/layout.py`: `TabsProcessor` tabstop callable returns `getattr(editor_buffer, 'tabstop', self.editor.tabstop)`.
   * Updated `vith/key_bindings.py`: `_insert_indentation` and `_shift_lines` use `_get_buffer_tabstop(editor, buff)`.
4. **Commands and Grammar (`vith/commands/`)**:
   * Extended `COMMAND_GRAMMAR` in `vith/commands/grammar.py` to recognize `set|setlocal|setl`.
   * Updated `set_command_execute` and `_set_int_option` in `vith/commands/commands.py`:
     * `:setlocal tabstop=N` / `:setl ts=N` sets `eb.tabstop = number` locally on the active buffer.
     * `:set tabstop=N` / `:set ts=N` sets both global `editor.tabstop` and active buffer's `eb.tabstop`.
     * `:set tabstop` / `:setlocal tabstop` displays the active buffer's effective tabstop.
     * `:set ft=...` resets buffer-local tabstop override so the new filetype's standard tabstop immediately takes effect.
   * Updated `vith/commands/preview.py`: live preview for `:setlocal ts=...` and `:set ft=...` with full rollback on abort.
   * Updated `vith/commands/completer.py`: `:setlocal ft=` supports filetype auto-completion.
5. **Comprehensive Tests**:
   * Added 11 tests in `tests/test_filetype_tabstops.py` verifying defaults, alias normalization, buffer filetype detection, shebang sniffing, command execution, local scoping, key bindings, and command previewing.
