# Quadratic $O(N^2)$ string concatenation in `:j` / `:join`

**Category:** performance / algorithms · **Area:** `vith/commands/editing.py` · **Found at:** Round 10 deep performance audit (2026-11-22, `v0.15.1` / rev 392) · **Fix status:** open

## Summary

In `join_lines` (`vith/commands/editing.py:327-335`), non-bang `:j` / `:join` concatenates lines via `joined = joined + ' ' + stripped` and `joined = joined + stripped`.[^src-editing] Because `joined + ' '` allocates a new string before appending `stripped`, CPython's in-place `+=` optimization never triggers and the growing prefix is copied twice per line, producing $\Theta(N^2 \cdot \bar{L})$ runtime.

## Evidence

Measured on `Python 3.15.2` joining `N` lines (~42 chars/line):

| Lines (`N`) | Current (`editing.py`) | $O(N)$ `list` + `''.join` | Speedup |
| ---: | ---: | ---: | ---: |
| 2,000 | 3.53 ms | 0.18 ms | **19.7×** |
| 5,000 | 18.24 ms | 0.36 ms | **50.3×** |
| 10,000 | 62.86 ms | 0.68 ms | **92.8×** |
| 20,000 | **258.66 ms** | **1.39 ms** | **185.4×** |

## Fix Direction

Accumulate pieces into a `list[str]` (tracking the last non-empty piece to decide whether to append `' '`) and join once with `''.join(parts)` in $O(\text{total chars})$.[^src-editing]
