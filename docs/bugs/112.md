## Fix direction

## Fix

All 10 items resolved and machine-verified (`pytest`, `mypy .`, `ruff check .`):

1. Removed redundant `if count is None` check in `ColdTextBuffer._cursor_vertical` (`vith/cold_text.py`).
2. Simplified `_name_under_cursor` in `vith/key_bindings.py` to a single `re.finditer(r'\S+', line)` loop.
3. Covered `find_previous_word_ending(..., count=-1)` with unit tests and updated its `prompt_toolkit` parity comment in `vith/thai/words.py`.
4–5. Removed unused `thai_classify`/`thai_clusters`/`thai_words`/`thai_patches` aliases from `vith/thai/__init__.py` and clearly marked internal/test re-exports there; retained the pre-reorg `vith.thai_words`/`thai_classify`/`thai_clusters`/`thai_patches` names as intentional lazy `__getattr__` compat shims in `vith/__init__.py` (rev 278 100% compat promise; no in-repo consumers, no import cost unless accessed).
6–7. Removed commented-out grammar code in `vith/commands/grammar.py` and dead `hasattr(self, 'application')` checks in `vith/editor.py`.
8. Removed obsolete Python 2 `(object)` base classes across `vith/editor_buffer.py`, `vith/editor.py`, `vith/reporting.py`, `vith/window_arrangement.py`, and `vith/commands/preview.py`.
9. Hoisted `_THAI_DIGIT_CPS`, `_THAI_SYMBOL_CPS` (as `frozenset`), `_build_thai_base_table()`, and `_THAI_BASE_CPS` above `is_thai_base` in `vith/thai/classify.py`.
10. Removed stale `build/` artifacts from the working tree.
