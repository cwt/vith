## Impact

(1) is the highest-risk copy: the direction/predicate *is* the Vi semantics for `w`/`b`/`e`/`ge`/`B`. Five copies mean a one-line off-by-one fix must be applied in five places (the failure mode of [043](043.md)).

## Fix direction

(1) Single `_iter_spans_from(doc, row, direction)` generator + per-motion predicate; keep `_iter_word_spans` as the reference implementation. (2)–(5) one helper each (`_insert_indent`, `_require_clean`, `_run_pager`, `_tmux_title_suffix`). (6) Preview imports `SET_COMMANDS` / `_set_int_option` validation instead of re-parsing. (8) Sort by `(-len, name)`.
