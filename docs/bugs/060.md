# Readability and test hygiene inventory (round 2: 1-tuple `super`, `cls` parameter, `bytes` shadowing, docstrings, `__import__`, `conftest` `~/.vith`)

**Category:** low readability / test hygiene · **Area:** `vith/`, `tests/` · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

Six readability and test-hygiene issues were identified at hg rev 191:

1. **Redundant 1-tuple and Python 2 `super(...)` in `SimpleArgToolbar.__init__`** ([`vith/layout.py:499-503`](../../vith/layout.py)[^src-lay]):
   ```python
   def __init__(self):
       (
           super(SimpleArgToolbar, self).__init__(
               Window(FormattedTextControl(self._get_formatted_text), height=1),
               filter=has_arg,
           ),
       )
   ```
   Wrapping `super().__init__(...)` in a trailing-comma 1-tuple `(...,)` is an accidental formatting artifact.
2. **Instance methods named `can_open_location(cls, location)` without `@classmethod`** ([`vith/io/base.py:16`](../../vith/io/base.py)[^src-base], [`vith/io/backends.py:24, 66, 94, 143`](../../vith/io/backends.py)[^src-io]):
   All five `can_open_location` definitions are regular instance methods (called on instances in `self.editor.io_backends`), yet their first parameter is named `cls` instead of `self`.
3. **Built-in `bytes` shadowed and unclosed `urlopen` response in `HttpIO.read`** ([`vith/io/backends.py:151-155`](../../vith/io/backends.py)[^src-io]):
   ```python
   def read(self, location):
       # Do Http request.
       bytes = urllib.request.urlopen(location).read()
       # Return decoded output.
       return _auto_decode(bytes)
   ```
   Assigns to `bytes` (shadowing the built-in type) and does not wrap `urllib.request.urlopen(location)` in a `with` statement to close the socket deterministically.
4. **Remaining copy-paste docstrings and function typo**:
   * [`vith/window_arrangement.py:21-22`](../../vith/window_arrangement.py)[^src-wa]: `class VSplit(Split): "Horizontal split."` (should be `"Vertical split."`).
   * [`vith/commands/commands.py:657`](../../vith/commands/commands.py)[^src-cmd]: `disable_breakindent` has docstring `"Enable the breakindent option."` (should be `"Disable the breakindent option."`).
   * [`vith/commands/commands.py:592`](../../vith/commands/commands.py)[^src-cmd]: `def searc_no_ignorecase(editor):` (missing `'h'` in `search_no_ignorecase`).
5. **Inline `__import__(...)` and redundant buffer creation in tests**:
   * [`tests/test_set_int_options.py:15-16`](../../tests/test_set_int_options.py)[^src-tset]: calls `ed.window_arrangement._add_editor_buffer(__import__('vith.editor_buffer', fromlist=['EditorBuffer']).EditorBuffer(ed))` immediately after `ed.load_initial_files([None])` (which already created an initial buffer), leaving 2 buffers in the test fixture and using an obfuscated inline `__import__`.
   * [`tests/test_completion.py:91, 109`](../../tests/test_completion.py)[^src-tcomp]: uses `__import__('prompt_toolkit.completion', fromlist=['CompleteEvent']).CompleteEvent()` instead of a top-level `from prompt_toolkit.completion import CompleteEvent`.
6. **Test fixture touches the user's real `~/.vith` directory** ([`tests/conftest.py:9-12`](../../tests/conftest.py)[^src-conf]):
   `editor()` in `tests/conftest.py` calls `Editor()` with default arguments, which runs `os.makedirs(os.path.expanduser('~/.vith'), exist_ok=True)` and creates a `FileHistory('~/.vith/.history')` in the developer's home directory rather than passing `config_directory=str(tmp_path)`.

## Fix direction

1. Replace `(super(SimpleArgToolbar, self).__init__(...),)` with `super().__init__(...)` in `vith/layout.py:499-503`.
2. Rename `cls` to `self` in `can_open_location` across `vith/io/base.py` and `vith/io/backends.py`.
3. Use `with urllib.request.urlopen(location) as response: data = response.read()` in `HttpIO.read`.
4. Fix the `VSplit` and `disable_breakindent` docstrings and rename `searc_no_ignorecase` to `search_no_ignorecase`.
5. Replace `__import__` calls in `tests/` with standard top-level imports and pass `config_directory=str(tmp_path)` in `tests/conftest.py`.
