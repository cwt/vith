# `vith.egg-info/` build debris and repo-only `.gitignore` (no `.hgignore`)

**Category:** hygiene · **Area:** repository root · **Found at:** deep review, hg rev 164 (2026-11-06)

## Evidence

* `vith.egg-info/` (PKG-INFO, SOURCES.txt, entry_points.txt, …) exists in the
  working copy; untracked build artifact.
* The repo tracks only [`.gitignore`](../../.gitignore) (which does cover
  `__pycache__/` and `*.egg-info/`), while `hg status` shows no unknown files
  — suppression of those paths relies on a machine-local global Mercurial
  ignore configuration, not on anything the repo defines.

## Impact

Non-reproducible working-copy behaviour between machines: fresh clones will
suddenly list `__pycache__/` and `vith.egg-info/` as unknown files.

## Fix direction

Add a repo `.hgignore` (`syntax: glob`: `__pycache__/`, `*.py[cod]`,
`*.egg-info/`, `.pytest_cache/` …) and remove the `vith.egg-info/` debris
from the working copy.
