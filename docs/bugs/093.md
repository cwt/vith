# Previewer leaks `ignore_case` on abort (091 regression)

**Category:** state leak / regression · **Area:** `vith/commands/preview.py`, `vith/commands/commands.py` · **Found at:** Round 5 audit, 2026-11-09, hg rev 256 (`v0.11.1`) · **Fix status:** open

## Summary

[091](091.md) claims `save()`/`restore()` now "cover the full catalog". They snapshot 19 attributes, but the 16th toggle `ignore_case` is missing:

| Catalog entry | Preview path | Saved / restored |
| :-- | :-- | :-- |
| `('ignorecase', 'ignore_case', ('ignorecase','ic'), ('noignorecase','noic'))` | `_TOGGLE_PREVIEWS['ic'] = ('ignore_case', True)` → `setattr(e, 'ignore_case', True)` | **absent** |

End-to-end probe with a real `Editor` (no stubs):

```text
initial ignore_case = False
e.enter_command_mode(); e.command_buffer.text = ':set ic'; e.leave_command_mode()
after typing ":set ic" = True
after Esc (should be False) = True      # leaked
```

`:set paste` behaves correctly (`True → False` after Esc), so this is exactly one missing catalog entry, not a general previewer failure.

## Evidence

* [`vith/commands/preview.py:45-72`](../../vith/commands/preview.py)[^src-preview] — `save()` lists 19 `self._*` attributes; no `_ignore_case`.
* [`vith/commands/preview.py:74-98`](../../vith/commands/preview.py)[^src-preview] — `restore()` lists the same 19; no `e.ignore_case`.
* [`vith/commands/preview.py:133-136`](../../vith/commands/preview.py)[^src-preview] — `_apply` writes the derived attribute for every alias.
* [`vith/commands/commands.py:566`](../../vith/commands/commands.py)[^src-cmd] — `SET_TOGGLE_GROUPS` entry for `ignorecase`.
* [`tests/test_preview.py:106-126`](../../tests/test_preview.py)[^src-test] — `test_previewer_restores_full_catalog_through_abort` checks only `paste`, `nowrap`, `nojedi`; `SAMPLE_STATE` (`:11-21`) omits `ignore_case`, so the gap is untested.

## Impact

Aborting a non-committing preview silently flips case-sensitivity for the rest of the session: normal/search highlighting and every later `:s` (whose `regex_flags` is derived from `editor.ignore_case`).

## Fix

Added `self._ignore_case = e.ignore_case` to `CommandPreviewer.save()` and `e.ignore_case = self._ignore_case` to `CommandPreviewer.restore()` in [`vith/commands/preview.py`](../../vith/commands/preview.py). Added `ignore_case` to `SAMPLE_STATE`, `:set ic`/`:set noignorecase` preview toggles, and abort-restore assertions in [`tests/test_preview.py`](../../tests/test_preview.py).
