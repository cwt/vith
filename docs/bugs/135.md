# `:g` substitute leaves the wrong last-search / last-replacement state

**Category:** wrong logic / duplicated substitute pipeline · **Area:** `vith/commands/commands.py` (`global_command`, `_global_execute_substitute`, `substitute`) · **Found at:** Round 8 full re-audit, 2026-11-19, hg rev 358 (`ff583fcf26ba`) · **Fix status:** open

## Summary

`substitute()` performs three state updates after a successful `:s`:

```python
editor.last_substitute_text = replace
search_state.text = search
editor.clear_hlsearch_suppression()
```

([`vith/commands/commands.py:2300-2303`](../../vith/commands/commands.py#L2300-L2303)).

`_global_execute_substitute()` — the separate implementation used by
`:g/pat/s/.../` and `:v/pat/s/.../` — only updates
`editor.last_substitute_text = replace`
([`vith/commands/commands.py:2874-2878`](../../vith/commands/commands.py#L2874-L2878)).
Worse, `global_command()` has already set the search state to the **global
pattern** ([`:2980-2981`](../../vith/commands/commands.py#L2980-L2981)), so the
substitute search itself is lost.

## Evidence

Buffer:

```text
foo bar
bar
```

Vim:

```text
:g/foo/s/bar/X/
:2
:s
```

→ line 2 becomes `X`, because the last substitute pattern is `bar` and the
last replacement is `X`.

Vith:

```text
after :g/foo/s/bar/X/   lines ['foo X', 'bar']
                        last_substitute_text 'X'
                        search_state.text 'foo'    # global pattern, not 'bar'
after :2 + :s           lines ['foo X', 'bar']      # Pattern not found
```

The same gap applies to the `n` (report-only) path: it reports matches but
does not set `search_state.text` or `last_substitute_text` and does not clear
the `:noh` suppression. The two implementations drift because they duplicate
the parse/compile/apply/update logic.

## Impact

* Repeating a substitute after a `:g` command uses the wrong pattern.
* Search highlighting (`n`/`N`, `/`) follows the global pattern instead of the
  substituted pattern.
* Any future `:s` bookkeeping change must be made twice.

## Fix direction

1. Extract a shared `_substitute_rows()` that returns matched rows/counts and
   applies the text, then call it from both `substitute()` and
   `_global_execute_substitute()`.
2. In the shared path, always set `search_state.text = search`,
   `last_substitute_text = replace`, and clear the `:noh` suppression on
   success (including `n`/`p` report paths where Vim updates the pattern).
3. Add a regression test for `:g/foo/s/bar/X/` followed by a bare `:s`, and
   for `:g/foo/s/bar/X/n`.
