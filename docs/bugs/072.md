## Fix record (2026-11-08, hg rev 262)

Per-keystroke: (1) dirty check is amortized O(1) via a length fast-path (exact memcmp semantics preserved for same-length edits), (2) completer cache key is `(lines, row, non-cursor-length)` instead of full-text slices, (3) `is_thai_base` folds into a precomputed `_THAI_BASE_CPS` table, (4) `_jedi_available` is `lru_cache`d, (5) `substitute` reuses the first split. Per-frame: (6) SARA-AM sanitizer iterates rows directly (no per-row list copy / set-union / generator chain), (7) the Thai gate decays via `reset_thai_text_gate_if_all_buffers_ascii` called from `sync_with_prompt_toolkit`, (8) lexer row resolved by [065](065.md), (9) `BufferListOverlay` compiles its search pattern once per frame, (10) `TabsControl` caches mouse handlers per index, (11) `reload()` notes the reloaded text.

9 tests across `test_editor_buffer.py` / `test_completion.py` / `test_thai.py` / `test_layout.py`.
