# `find_thai_cluster_end` treats marked `ร` + `ร` as Thai Ro Han (`รร`)

**Category:** Thai / syllable heuristic · **Area:** `vith/thai/words.py` · **Found at:** Round 18 full-project audit (2026-11-24, `v0.16.5`, hg rev `458:d2d313328875`) · **Fix status:** fixed (hg rev 482)

## Summary

In Thai orthography, Ro Han (`รร`, e.g. `ธรรม`, `กรรม`, `บรรจุ`) consists of two consecutive `ร` (`U+0E23`) consonants where the *first* `ร` never carries a combining vowel or tone mark (`r1_end == after_base + 1`). `find_thai_cluster_end()` advances `r1_end = next_cell_offset(line, after_base, 1)` over any combining marks on the first `ร` and still treats a following `ร` at `r1_end` as Ro Han:[^src]

```python
after_base = next_cell_offset(line, pos, 1)
if after_base < n and ord(line[after_base]) == 0x0E23:
    r1_end = next_cell_offset(line, after_base, 1)
    if r1_end < n and ord(line[r1_end]) == 0x0E23:
        pos = next_cell_offset(line, r1_end, 1)
```

When a consonant cluster `กรี่` or `บรี้` (`C` + `ร` + combining vowel/tone) is immediately followed by a syllable starting with `ร` (`รุก`, `รำ`), Tier-2 segmentation merges both `ร` cells into a single syllable.

## Evidence

Direct probe of `find_thai_cluster_end(word, 0)`:

| Input | Expected first cluster | Actual `find_thai_cluster_end(word, 0)` |
| :--- | :--- | :--- |
| `'ธรรม'` | `'ธรร'` (`3`) | `'ธรร'` (`3`) |
| `'กรี่รุก'` | `'ก'` (`1`) or `'กรี่'` (`4`), never `'กรี่รุ'` | `'กรี่รุ'` (`6`) |
| `'บรี้รำ'` | `'บ'` (`1`) or `'บรี้'` (`4`), never `'บรี้รำ'` | `'บรี้รำ'` (`6`) |

## Fix Direction

1. Require `r1_end == after_base + 1` (no combining marks on the first `ร`) before matching the second `ร` as Ro Han (`รร`).
2. Add regression tests in `tests/test_thai.py` verifying `'ธรรม'` stays `3` while `'กรี่รุก'` and `'บรี้รำ'` do not merge across the second `ร`.
