# Opening `~` or `~/dir` fails with `IsADirectoryError` because `DirectoryIO` and `FileIO.can_open_location` omit `expanduser`

**Category:** wrong logic · **Area:** `vith/io/backends.py` (`DirectoryIO`, `FileIO`) · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

`EditorBuffer.read` (`vith/editor_buffer.py:114-149`)[^src-eb] iterates through `editor.io_backends` (`DirectoryIO`, `FileIO`, `GZipFileIO`, `HttpIO`) and selects the first backend where `io.can_open_location(self.location)` returns `True`.

In `vith/io/backends.py`[^src-io]:
* `DirectoryIO.can_open_location(cls, location)` (line 95), `DirectoryIO.exists(self, location)` (line 98), and `DirectoryIO.read(self, location)` (line 103) call `os.path.isdir(location)` / `os.listdir(location)` **without** `os.path.expanduser(location)`.
* `FileIO.can_open_location(cls, location)` (line 26) checks `not os.path.isdir(location)` **without** `os.path.expanduser(location)`, whereas `FileIO.exists` (line 29) and `FileIO.read` (line 34) **do** call `os.path.expanduser(location)`.

Consequently, when a user opens `~` or `~/some_dir` (via `:e ~`, `:sp ~/dir`, or CLI `vith ~`):
1. `DirectoryIO.can_open_location('~')` returns `False` because `os.path.isdir('~')` is `False`.
2. `FileIO.can_open_location('~')` returns `True` because `not os.path.isdir('~')` is `True`.
3. `DirectoryIO.can_open_location('~')` returns `False` (because `os.path.isdir('~')` is False without `expanduser`), so `FileIO.can_open_location('~')` returns `True` (because `not os.path.isdir('~')` is True); `EditorBuffer.read` then selects `FileIO`, whose `read('~')` expands `'~'` to `/Users/<user>` and calls `open('/Users/<user>', ...)`, raising `IsADirectoryError: [Errno 21] Is a directory`.

## Evidence

* [`vith/io/backends.py:24-35, 94-104`](../../vith/io/backends.py)[^src-io]:
  ```python
  class FileIO(EditorIO):
      def can_open_location(cls, location):
          return '://' not in location and not os.path.isdir(location)
      ...
      def read(self, location):
          location = os.path.expanduser(location)
  ...
  class DirectoryIO(EditorIO):
      def can_open_location(cls, location):
          return os.path.isdir(location)

      def exists(self, location):
          return os.path.isdir(location)

      def read(self, location):
          content = sorted(os.listdir(location))
  ```
* **Live probe**:
  ```python
  >>> from vith.editor import Editor
  >>> e = Editor()
  >>> e.load_initial_files(['~'])
  >>> e.message
  "Cannot read '~': IsADirectoryError(21, 'Is a directory')"
  ```

## Impact

Opening `~` or any `~/...` directory fails with `IsADirectoryError` instead of opening the File Explorer (`DirectoryIO`).

## Fix direction

Call `location = os.path.expanduser(location)` in `DirectoryIO.can_open_location`, `DirectoryIO.exists`, `DirectoryIO.read`, and `FileIO.can_open_location`.
