## Fix direction

* Extract `write_target()` (normalize + same-file exemption), `_substitute_rows()`, `close_or_exit()`, and `_effective_tabstop()/shiftwidth()` helpers.
* Derive `_default_options` and `_CONFIG_OPTION_MAP` from the `:set` catalog at import time, or move the catalog to a leaf module both import.
* Add an `EditorIO.find_backend(location)` helper and use it everywhere.
* Remove the unused import/sentinel/parameter/2-tuple branch, or mark them with a real use/test.
* Update the `is_sara_am` docstring.
