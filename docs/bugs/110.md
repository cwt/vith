# Bugs and wrong-logic inventory (Round 6)

**Category:** wrong logic / defect · **Found at:** Round 6 read-only deep audit, 2026-11-09 · **Fix status:** open

## Findings

| # | Location | Defect | Evidence / notes |
| :-- | :-- | :-- | :-- |
| 1 | `vith/commands/commands.py:718` | `substitute()` tracks `last_substituted_row` via `result != original`, so a match whose replacement is identical to the matched text is reported as “Pattern not found”. | Match presence should be tracked instead. |
| 2 | `vith/commands/commands.py:443` | `:wqa` is registered without `accepts_force=True`, so `:wqa!` is rejected with “No ! allowed”. | Vim allows forced write-all-and-quit. |
| 3 | `vith/commands/handler.py:7-47` | Empty/whitespace command input is not treated as a no-op; falls through to “Not an editor command: ”. | `COMMAND_GRAMMAR.match('')` succeeds with no command. |
| 4 | `vith/reporting.py:127-131` | `_FlakesReporter.syntaxError` and `unexpectedError` are no-ops, so pyflakes syntax errors are never surfaced. | Module purpose is to report errors. |
| 5 | `vith/reporting.py:94-96` | Byte-offset to character column uses `errors='replace'`, which can miscount on invalid UTF-8. | Should decode with a counting-safe method. |
| 6 | `vith/reporting.py:101-106` | `end_index` loop indexes `document.text` without ensuring `start_index` is in bounds for the current line. | Potential `IndexError` on stale rows. |
| 7 | `vith/cold_text.py:275-281` | `undo()` discards snapshots whose text equals the current text without pushing them to redo. | Can lose intermediate history. |
| 8 | `vith/cold_text.py:191-199` | `reset()` recreates undo/redo stacks but does not reset `_vith_cell_column`. | Stale vertical-cursor state survives reset. |
| 9 | `vith/io/backends.py:145-146` | `HttpIO.exists()` returns `NotImplemented` (truthy sentinel) instead of a boolean. | Callers treat “unknown” as “exists”. |
| 10 | `vith/editor_buffer.py:234-248` | On `UnicodeEncodeError`, encoding is mutated to `utf-8` before the second `io.write`; a failed second write leaves a changed encoding. | State mutation should follow success. |
| 11 | `vith/thai/patches.py:481-482` | `data_buffer[sy][sx]` is accessed without `.get()`; stale `rowcol_to_yx` entry raises `KeyError`. | Latent crash on stale entries. |
| 12 | `vith/thai/patches.py:611-622` | Autowrap path does `screen.zero_width_escapes[y]` (direct index) and may raise if the row is missing. | Latent crash. |

## Fix direction

Address each item in its owning module with regression tests; prefer explicit `None`/bounds guards and state mutation only after successful I/O.
