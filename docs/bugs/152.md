## Fix direction

1. Derive `Editor._default_options` from `SET_TOGGLE_GROUPS`, `SET_INT_OPTIONS`, `SET_LIST_OPTIONS` (shallow-copying list defaults), plus `'fileformat'`.
2. Derive `_CONFIG_OPTION_MAP` from the `:set` catalog merged with non-catalog TOML keys (`cold_text_compression`, `cold_text_compression_level`, `fileformat`/`ff`, `colorcolumn`/`cc`); keep `_TOML_DETECTION_KEYS` cautious about very short aliases (`ts`, `so`, `nu`, `ai`) that could collide with top-level variables in legacy Python `~/.vithrc` files.
3. Reuse `_resolve_editor_buffer` across `key_bindings.py`, optionally share a small buffer-local/global int-option setter helper between `options.py` and `preview.py`, and keep raw configured `shiftwidth` queries (`_get_int_option_value`) distinct from effective `EditorBuffer.shiftwidth`.
4. Extract a shared 1-based address resolver in `vith/commands/ranges.py`, preserving the bare `'0'` → row `0` rule in `resolve_line_address`.
5. Extract one pure `resolve_ignore_case(ignore_case, smartcase, pattern)` helper (including the `\S`/`[A-Z]` literal stripping) and call it from both `Editor.should_ignore_case` and `substitution.should_ignore_case`'s fallback path.
6. Unify path normalization / same-file comparison in a shared helper (or `EditorBuffer`) used by both `vith/commands/files.py` and `EditorBuffer.write` (`L446` read-only guard and `L475` `updates_buffer` check), with a regression test for `:set ro` + `:w <symlink>`.
