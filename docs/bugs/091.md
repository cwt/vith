# Command previewer leaked non-`:set`-listed attributes on abort (073 regression)

**Category:** state leak (stem: 028/050 preview machinery / 073 regression) · **Area:** `vith/commands/preview.py` · **Found at:** stem audit 2026-11-08 · **Fixed at:** hg rev 270

## Summary (pre-fix probes)

The derived `_TOGGLE_PREVIEWS` covers 16 toggles; `save()`/`restore()` snapshot
only 9 attributes, so every catalog option not in that list leaked its plain
value on abort:

```
:set nowrap  + Esc → wrap_lines=False persists
:set paste   + Esc → paste_mode=True persists
:set noic    + Esc → ignore_case=False persists
:set nonu...     (only the 9 saved attrs restored fine)
```

Test gap: `test_preview.py`'s `SAMPLE_STATE` sweeps only the 9 restorable
attributes. Bonus: `_preview_list_value` ignored its `attribute` parameter and
always wrote `editor.colorcolumn`.

## Fix

`save()`/`restore()` now cover the full catalog: `paste_mode`, `show_wildmenu`,
`expand_tab`, `incsearch`, `display_unprintable_characters`, `enable_jedi`,
`wrap_lines`, `break_indent`, `enable_mouse_support` in addition to the old
nine. `_preview_list_value` honors its derived attribute. Tests:
`tests/test_preview.py::test_previewer_restores_full_catalog_through_abort`
and `::test_preview_list_value_uses_catalog_attribute`.

> Note: the pre-rev-265 028-consolidated spec table matched the leaky set
> exactly — the regression arrived with 265's catalog single-source, rolled
> back here by making the preview mindful of the catalog (single-state provenance).
