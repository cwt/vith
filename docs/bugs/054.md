# Miscellaneous logic defects (`is_thai_base` digits, `close_buffer` tab index, `hsplit`/`vsplit` assert, preview mismatches, `ignorecase`, file explorer, `tabstop`, `_try_char`)

**Category:** wrong logic · **Area:** `vith/thai.py`, `vith/window_arrangement.py`, `vith/commands/`, `vith/key_bindings.py`, `vith/layout.py`, `vith/editor.py` · **Found at:** deep review, hg rev 191 (2026-11-07)

| 1 | [`vith/thai.py:207-220`](../../vith/thai.py)[^src-thai] | `is_thai_base(cp)` returns `True` for **every** non-combining codepoint in `0x0E01..0x0E5B` and `0x0E81..0x0EDF`, including Thai/Lao digits (`0x0E50..0x0E59`, `0x0ED0..0x0ED9`) and punctuation/currency symbols (`฿` `0x0E3F`, `๏` `0x0E4F`, `๚` `0x0E5A`, `๛` `0x0E5B`). ## Fix direction

1. **`is_thai_base`**: Exclude Thai/Lao digits (`0x0E50..0x0E59`, `0x0ED0..0x0ED9`) and non-letter symbols (`0x0E3F`, `0x0E4F`, `0x0E5A`, `0x0E5B`) from `is_thai_base` so contiguous digits group via the non-Thai word path.
2. **`close_buffer`**: Iterate in reverse or decrement `self.active_tab_index` when `i < self.active_tab_index` (and clamp to `len(self.tab_pages) - 1`).
3. **`hsplit`/`vsplit`**: Assert `(location is not None) + (text is not None) + bool(new) <= 1`.
4. **`CommandPreviewer`**: Initialize backup attributes in `__init__` (or a ` _saved = False` flag), allow `>= 0` for `scrolloff` in `_preview_int_value`, and align `_preview_colorcolumn` with `set_colorcolumn`.
5. **`ignore_case`**: Pass `ignore_case=Condition(lambda: editor.ignore_case)` to `SearchToolbar` in `vith/layout.py:565` and `flags=re.IGNORECASE if editor.ignore_case else 0` in `substitute`.
6. **File Explorer**: Ignore lines starting with `'" '` in `open_Path`, and mark `in_file_explorer_mode` buffers read-only (or `has_unsaved_changes = False`).
7. **`tabstop`**: Insert `' ' * editor.tabstop` in `indent_line` and `autocomplete_or_indent`.
8. **`_try_char`**: Guard `encoding = getattr(sys.stdout, 'encoding', None) or 'utf-8'`.
