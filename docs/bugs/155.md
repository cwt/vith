# Startup `FiletypeTabstops(DEFAULT_FILETYPE_TABSTOPS)` eagerly imports 32 Pygments lexer modules

**Category:** performance / startup · **Area:** `vith/editor.py` · **Found at:** Round 10 deep performance audit (2026-11-22, `v0.15.1` / rev 392) · **Fix status:** open

## Summary

`Editor.__init__` executes `self._filetype_tabstops = FiletypeTabstops(DEFAULT_FILETYPE_TABSTOPS)` on every startup.[^src-editor] `FiletypeTabstops.__setitem__` runs `_canonical_filetype(key)` → `pygments.lexers.get_lexer_by_name(name)` for all 34 built-in entries, dynamically importing 32 `pygments.lexers.*` modules (including large builtin tables like `_lilypond_builtins`, `_postgres_builtins`, `_googlesql_builtins`, `_mysql_builtins`, `_tsql_builtins`, `_php_builtins`, `_scheme_builtins`) and scanning `importlib.metadata` plugin entry points for unrecognized names (`vue`, `svelte`, `gitcommit`).

## Evidence

Measured in fresh Python 3.15.2 subprocesses (`Pygments 2.21.0`):

| Phase | Cold time | Modules loaded |
| :--- | ---: | :--- |
| Total CLI startup (`import vith.entry_points.run_vith` + `Editor()`) | **297.58 ms** | — |
| `FiletypeTabstops(DEFAULT_FILETYPE_TABSTOPS)` alone | **187.82 ms** | +33 modules (**32 `pygments.lexers.*`**) |
| `Editor()` after `_canonical_filetype` is warm | **6.07 ms** | — |
| Resolving all 927 aliases from `pygments.lexers._mapping.LEXERS` | **0.183 ms** | **0 lexer modules** (0 mismatches across all 34 defaults) |

`FiletypeTabstops` initialization accounts for **~63% of total cold CLI startup** and **~97% of `Editor()` construction**, dwarfing the 18 ms saved by P2's `_LazyStylesDict` in [`../speed_latency_plan.md`](../speed_latency_plan.md).

## Fix Direction

1. Build a lazy alias-to-canonical-alias lookup table in `_canonical_filetype` from `pygments.lexers._mapping.LEXERS` (which stores `(module, name, aliases, filenames, mimetypes)` without importing any lexer module), falling back to `get_lexer_by_name` only for unrecognized/third-party plugin aliases (and never for names already known to be non-Pygments built-in keys such as `vue`, `svelte`, `gitcommit` unless explicitly queried).
2. Add a fast path in `FiletypeTabstops` (or `_canonical_filetype`) so constructing `FiletypeTabstops(DEFAULT_FILETYPE_TABSTOPS)` imports **zero** `pygments.lexers.*` modules while preserving 100% alias equivalence (`py` → `python`, `js` → `javascript`, `ts` → `typescript`, etc.).
