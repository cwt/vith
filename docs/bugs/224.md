# `:substitute` missing from Ex command Tab completion

**Category:** commands / completion · **Area:** `vith/commands/completer.py`, `vith/commands/handler.py` · **Found at:** Round 18 full-project audit (2026-11-24, `v0.16.5`, hg rev `458:d2d313328875`) · **Fix status:** open

## Summary

`create_command_completer()` builds the `WordCompleter` for the `'command'` grammar variable from `get_commands()` (`COMMANDS_TO_HANDLERS.keys()`).[^src-comp] Because `s` and `substitute` are dispatched via a special `elif command in ('s', 'substitute'):` branch in `handle_command()` rather than `@_cmd`, neither name is in `COMMANDS_TO_HANDLERS`, and typing `:sub<Tab>` yields no completions.[^src-handler]

## Evidence

Live probe:

```python
comp = create_command_completer(editor)
list(comp.get_completions(Document("sub", 3), CompleteEvent()))
# Actual: []   (Expected: [Completion(text='substitute ', ...)])
```

## Fix Direction

1. Register `s` and `substitute` via `@_cmd('s')` / `@_cmd('substitute')` (removing the special-case `elif` in `handle_command`), or include `('s', 'substitute')` in the completer's command list (without a trailing space if delimiter immediately follows, or `'substitute'`).
2. Add a completion test asserting `:sub<Tab>` offers `substitute`.
