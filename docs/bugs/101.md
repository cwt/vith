## Impact

Four of the five are regression tests attached to previously fixed findings ([039](039.md), [044](044.md), [086](086.md), [072](072.md)); they provide no protection if those bugs return. The suite still reports 198 passed / 1 skipped.

## Fix direction

Replace (1) with `assert 'ที่ดิน' in comps`; rewrite (2) to build a `KeyPressEvent`-like stub and assert the indent is actually inserted at the line start; add explicit result assertions to (3) and (5); for (4) assert the cache behaviour (`cache_clear()` then `cache_info()`), not a version-dependent constant.
