# Unoptimized algorithms and memory-growth inventory (Round 6)

**Category:** performance / memory · **Found at:** Round 6 read-only deep audit, 2026-11-09 · **Fix status:** fixed

## Inventory

| # | Location | Issue | Notes |
| :-- | :-- | :-- | :-- |
| 1 | `vith/lexer.py:22` | Unbounded `_STYLE_TOKEN_CACHE`. | Memory growth risk. |
| 2 | `vith/thai/clusters.py:87-101` | `cell_starts` LRU cache has no size guard. | Large distinct lines can pin memory. |
| 3 | `vith/thai/words.py:213-220` | `find_thai_word_breaks` rescans entire text for `all_thai`/`has_thai_base` on every call. | Repeated work. |
| 4 | `vith/thai/patches.py:328-332` | SARA-AM loop builds `all_xs` from every column, then filters per `x`. | O(columns log columns) per row. |
| 5 | `vith/thai/patches.py:457-474` | Window copy-body patch iterates every visible row even without combining marks at right margin. | Candidate fast path only after scan. |
| 6 | `vith/editor.py:254-272` | `current_editor_buffer` O(n) scan on every access. | Hot path. |
| 7 | `vith/layout.py:101-110` | `TabsControl.tab_handlers` never cleared/pruned. | Lifetime cache. |
| 8 | `vith/window_arrangement.py:53-59` | `TabPage.windows()` rebuilds full split tree on every call. | Repeated by many callers. |

## Fix direction

Bound caches, add fast paths, and cache/reuse traversal results where safe.

## Fix

All 8 items resolved and machine-verified (`pytest`, `mypy .`, `ruff check .`):

1. Replaced unbounded `_STYLE_TOKEN_CACHE` in `vith/lexer.py` with `@lru_cache(maxsize=4096)` on `_style_classname`.
2. Added `_CELL_STARTS_CACHE_MAX_LINE = 65536` size guard around `_cell_starts_cached` (`@lru_cache(maxsize=4096)`) in `vith/thai/clusters.py`.
3. Replaced the Python per-character `all_thai`/`has_thai_base` loop in `find_thai_word_breaks` (`vith/thai/words.py`) with precompiled C regex checks `_NON_THAI_RE` and `_THAI_BASE_RE`.
4. Optimized `_sanitize_and_invalidate_sara_am` in `vith/thai/patches.py` to collect only SARA AM columns `x >= 1` in a single pass instead of building and sorting all row keys.
5. Optimized `_patched_copy_body` in `vith/thai/patches.py` to iterate `O(min(len(data_buffer), window_height))` populated visible rows.
6. Attached `_vith_editor_buffer_ref` weakref on `EditorBuffer.buffer` (`vith/editor_buffer.py`) and updated `Editor.current_editor_buffer` (`vith/editor.py`) to resolve in $O(1)$ and fast-reject `command_buffer`/`search_buffer`.
7. Pruned stale tab indices (`idx >= len(tab_pages)`) from `TabsControl.tab_handlers` in `vith/layout.py`.
8. Cached the flattened window list in `TabPage._windows_cache` (`vith/window_arrangement.py`), invalidating on `_split` and `close_active_window`.
