# `FiletypeTabstops` alias/delete/validation gap

**Category:** editor / config · **Area:** `vith/editor.py` · **Found at:** Round 17 read-only re-audit (2026-11-23, `v0.16.4`) · **Fix status:** open

## Summary

`FiletypeTabstops` canonicalizes only `__setitem__`, `__getitem__`, `get`, `__contains__`, and `update`.[^src] The remaining mutating/lookup methods inherited from `dict` (`__delitem__`, `pop`, `popitem`, `setdefault`, `clear`, `__or__`) bypass canonicalization, breaking the documented alias-sync contract. `__setitem__` also does `int(value)` without bounds checking, so `True -> 1`, `2.9 -> 2`, and `0` are silently stored.[^src-set]

## Evidence

Live probe against the shipped class:

| operation | expected | actual |
| :--- | :--- | :--- |
| `'py' in FiletypeTabstops({'python': 4})` | `True` | `True` |
| `ft.get('py')` | `4` | `4` |
| `del ft['py']` | deletes `python` entry | `KeyError: 'py'` |
| `ft.pop('py')` | `4` | `KeyError: 'py'` |
| `ft['python'] = 0` | `ValueError` | stores `{'python': 0}` |
| `ft['python'] = True` | `ValueError` | stores `{'python': 1}` |

## Fix Direction

1. Override `__delitem__`, `pop`, `popitem`, `setdefault` (and `__or__`/`__ior__` if used) to canonicalize before delegating.
2. Validate in `__setitem__`: require `int` (not `bool`) and `value >= 1`, raising `ValueError` otherwise.
3. Regression tests for alias delete/pop and invalid-value rejection.
