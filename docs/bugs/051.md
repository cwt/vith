# `:colo <scheme>` is registered in `commands.py` but rejected by `COMMAND_GRAMMAR` and ignored by `CommandPreviewer`

**Category:** wrong logic · **Area:** `vith/commands/grammar.py`, `vith/commands/preview.py`, `vith/commands/commands.py` · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

`vith/commands/commands.py:438-443`[^src-cmd] registers both `@_cmd('colorscheme')` and `@_cmd('colo')` on `color_scheme`. However:

1. `COMMAND_GRAMMAR` (`vith/commands/grammar.py:29`)[^src-gram] hardcodes `(?P<command>colorscheme) \s+ (?P<colorscheme>[^\s]+)`. Because `:colo <scheme>` has a space and an argument, it does not match the `colorscheme` branch or the single-token fallback branch `(?P<command>[^\s!]+)`. `COMMAND_GRAMMAR.match(':colo vim')` returns `None`, and `handle_command` (`vith/commands/handler.py:12-14`)[^src-hand] silently drops the command without even showing an `Unknown command` message.
2. `CommandPreviewer._apply` (`vith/commands/preview.py:95`)[^src-prev] checks `if command == 'colorscheme':` instead of `if command in ('colorscheme', 'colo'):`.

## Evidence

* [`vith/commands/commands.py:438-443`](../../vith/commands/commands.py)[^src-cmd]:
  ```python
  @_cmd('colorscheme')
  @_cmd('colo')
  def color_scheme(editor, variables):
      "Use a color scheme."
  ```
* [`vith/commands/grammar.py:29`](../../vith/commands/grammar.py)[^src-gram]:
  ```python
  (?P<command>colorscheme) \s+ (?P<colorscheme>[^\s]+)  |
  ```
* **Live probe**:
  ```python
  >>> from vith.commands.grammar import COMMAND_GRAMMAR
  >>> COMMAND_GRAMMAR.match('colo default') is None
  True
  ```

## Impact

Typing `:colo <scheme>`Neither previews nor applies the color scheme; typing any unrecognized multi-word command (`:foo bar`) is silently ignored instead of reporting `Unknown command`.

## Fix direction

1. Update `vith/commands/grammar.py:29` to `(?P<command>colorscheme|colo) \s+ (?P<colorscheme>[^\s]+)`.
2. Update `vith/commands/preview.py:95` to `if command in ('colorscheme', 'colo'):`.
3. In `vith/commands/handler.py:12-14`, show `editor.show_message(f'Unknown command: {input_string}')` when `COMMAND_GRAMMAR.match(input_string)` returns `None`.
