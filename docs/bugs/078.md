# Readability: `thai.py` monolith, import-time patching, decorators that return the wrong thing, remaining `lambda`s

**Category:** low readability / maintainability · **Area:** `vith/thai.py`, `vith/commands/commands.py`, `vith/key_bindings.py`, `vith/layout.py`, `vith/__init__.py` · **Found at:** deep review, hg rev 87de3a3 (2026-11-08)

## Summary

| # | Location | Issue |
|---|---|---|
| 1 | `thai.py` (1,461 lines) | Four modules in one file: classification + clusters + libthai `ctypes` + word spans + `Document`/`KeyProcessor`/`TextObject` patching + `Window._copy_body` + renderer escapes + gate. Splitting into `thai_classify` / `thai_clusters` / `thai_words` / `thai_patches` / `thai_renderer` makes each testable in isolation. |
| 2 | `thai.py:1460-1461` | `install_prompt_toolkit_thai_patches()` runs on `import vith.thai` (with a hard-coded startup self-test). Import ≠ patch contract: tests, bench and user scripts patch global prompt_toolkit irreversibly. Install only from `Editor.__init__`; move the self-test to `tests/`. |
| 3 | `commands.py:62-106` | `location_cmd`/`cmd` register a *wrapper* but `return func` (original). Stacking `@cmd('a') @cmd('b')` only works because the outer decorator sees the original. Return the wrapper (and chain). |
| 4 | `key_bindings.py:258`, `layout.py:570` | Two remaining `lambda`s (`tildeop`, `ignore_case`) vs the repo’s own “avoid `lambda` under all circumstances” rule. Named `Condition` functions. |
| 5 | `layout.py` (`super(X, self)`), `editor.py:37` (`class Editor(object)`), single-quoted tuples | Legacy/py2 style mixed with modern `thai.py`/`cold_text.py` style. `ruff format` + `super()` sweep. |
| 6 | `__init__.py:18,23` | Fallback `"0.10.0"` hard-coded twice (duplicates `pyproject.toml`). Single constant. |
| 7 | `process.py:26-33` | `_NSGetArgv()` fetched twice with `restype` changed mid-function. Fetch once. |

## Impact

None of these crash today; (1)–(3) are why the Thai patch cluster ([065](065.md), [080](080.md)) is hard to reason about and regresses.

## Fix direction

Split `thai.py` (behaviour-preserving, import surface unchanged via re-exports), remove the import-time install, fix decorator returns, named `Condition`s. Keep `__all__` stable during the split.
