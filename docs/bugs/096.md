# `:e <location>` ignores unsaved changes and `force`

**Category:** wrong logic / Vim semantics / dead parameter · **Area:** `vith/commands/commands.py` · **Found at:** Round 5 audit, 2026-11-09, hg rev 256 · **Fix status:** open

## Summary

```python
@location_cmd('o', accepts_force=True)
@location_cmd('open', accepts_force=True)
@location_cmd('e', accepts_force=True)
@location_cmd('edit', accepts_force=True)
def buffer_edit(editor, location, force=False):
    if location is None:
        ... _confirm_unsaved_changes(editor, force) ...   # reload form only
    else:
        editor.window_arrangement.open_buffer(location, show_in_current_window=True)  # force unused
```

Probe:

```text
before: dirty=True  active=[New file]
:e /tmp/xxx.txt -> message=None  active now=/tmp/xxx.txt  old dirty buffer still open=True
:e! /tmp/xxx.txt -> identical behaviour
```

`accepts_force=True` on all four aliases means `:e!` passes `force=True`, which the `else` branch never reads — a **dead parameter** and a copy-paste divergence from `:b`/`:bn`/`:bp`/`:bd`, which all route through `_confirm_unsaved_changes`.

## Evidence

* [`vith/commands/commands.py:357-370`](../../vith/commands/commands.py)[^src-cmd] — `buffer_edit`; `force` referenced only in the `location is None` branch.
* [`vith/commands/commands.py:27-38`](../../vith/commands/commands.py)[^src-cmd] — `_confirm_unsaved_changes` docstring: *"shared by `:b`, `:bn`, `:bp`, `:bd`/`:bw` and `:e`"*.
* [`docs/bugs/073.md:64`](073.md) — fix record item 2: `_confirm_unsaved_changes` *"(`：b` family + `:e`)"*.
* No test in `tests/` asserts an E37-style warning for `:e <file>` on a dirty buffer.

## Impact

`:e file` silently shelves a modified buffer (no `E37: No write since last change (add ! to override)`), and `:e! file` is indistinguishable from `:e file`. Not data loss — the old buffer stays open and hidden — but the guard and the documented force semantics are both absent.

## Fix

In `buffer_edit()` ([`vith/commands/commands.py`](../../vith/commands/commands.py)):
- Routed the `location is not None` branch through `_confirm_unsaved_changes(editor, force)` so that switching buffers via `:e <file>` warns with `"No write since last change (add ! to override)"` when the active buffer is modified, and `:e! <file>` forces the buffer switch.
- Added regression tests in [`tests/test_write_commands.py`](../../tests/test_write_commands.py).
