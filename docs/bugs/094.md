# `:s` flags are parsed but silently ignored

**Category:** wrong logic / incomplete implementation · **Area:** `vith/commands/grammar.py`, `vith/commands/handler.py`, `vith/commands/commands.py` · **Found at:** Round 5 audit, 2026-11-09, hg rev 256 · **Fix status:** open

## Summary

[083](083.md) rebuilt the grammar tail as `(?P<flags> ( / \w* )* )?` and explicitly cites `/gI` as accepted. The handler implements only `g`:

```python
regex_flags = re.IGNORECASE if getattr(editor, 'ignore_case', False) else 0   # commands.py:664
sub_count = 0 if 'g' in flags else 1                                          # commands.py:685
```

`handler.py` merely does `flags.lstrip('/')`. Every other Vim substitute flag is parsed and thrown away.

| Command | Input | Current result | Vim result |
| :-- | :-- | :-- | :-- |
| `:s/foo/X/i` | `Foo foo FOO` | `Foo X FOO` | `X X X` |
| `:s/foo/X/gI` with `:set ic` | `Foo foo FOO` | all three replaced | only `foo` replaced |
| flags reaching `substitute()` | `:s/foo/X/i` | `'i'` | — |

## Evidence

* [`vith/commands/grammar.py:22`](../../vith/commands/grammar.py)[^src-grammar] — `(?P<flags> ( / \w* )* )?` accepts arbitrary word flags.
* [`vith/commands/handler.py:42`](../../vith/commands/handler.py)[^src-handler] — `flags = flags.lstrip('/')`; no further parsing.
* [`vith/commands/commands.py:664`](../../vith/commands/commands.py)[^src-cmd] — `regex_flags` reads only `editor.ignore_case`.
* [`vith/commands/commands.py:685`](../../vith/commands/commands.py)[^src-cmd] — only `'g' in flags` is consulted.
* [`tests/test_substitute.py:152-207`](../../tests/test_substitute.py)[^src-test] — flags tests cover only empty flags, `g`, `//g` and `:0,1s`; no `i`/`I` case.
* [083](083.md) note excludes only `:%s` / `:$s` / `:'<,'>` *ranges*, not flags.

## Impact

Accepting-but-ignoring is worse than rejecting: a user gets a silently wrong substitution (or a silently wrong `:set ic` override) with no error. `c` (confirm), `n` (count-only) and `p` (print) are also accepted yet ignored.

## Fix direction

Parse the flag string: `i` adds `re.IGNORECASE`, `I` removes it regardless of `'ignorecase'`, `g` sets `count=0`, repeated flags deduplicate; reject (`E…: Invalid substitute flags`) or explicitly document any remaining flags instead of ignoring them. Add regression tests for `i`, `I`, and an unknown flag.
