# `TabPage` can be left empty (`VSplit([])`, `active_window = None`) and `cycle_focus` then raises

**Category:** wrong logic / invariant by convention · **Area:** `vith/window_arrangement.py` (`TabPage`) · **Found at:** deep review, hg rev 87de3a3 (2026-11-08)

## Summary

`TabPage.close_active_window` sets `active_window = None` when the root split empties. The invariant “a `TabPage` is never empty” is enforced only by `WindowArrangement.close_window` (window-count check → `close_tab`). Other callers bypass it:

* `WindowArrangement.close_buffer` (line 485) calls `self.active_tab.close_active_window()` directly.
* `TabPage.cycle_focus` does `windows.index(self.active_window)` → `ValueError` when `None`.
* `EditorLayout.update` will build `VSplit([])` for prompt_toolkit.

Residual fragility from [040](040.md) / [041](041.md) (both fixed at the `WindowArrangement` layer, not the `TabPage` layer). The same function’s `close_buffer` tab-index bookkeeping iterates `self.tab_pages[:]` (snapshot) while mutating the live list, comparing snapshot index `i` against live `active_tab_index` — correct by accident for single removal, fragile for multi-tab multi-window closes.

## Evidence

* [`vith/window_arrangement.py:169-194`](../../vith/window_arrangement.py)[^src-wa] — empty-root → `None`; collapse `len==1` logic.
* [`vith/window_arrangement.py:196-202`](../../vith/window_arrangement.py) — unguarded `windows.index(...)`.
* [`vith/window_arrangement.py:257-272`](../../vith/window_arrangement.py) — the only guard (in `close_window`).
* [`vith/window_arrangement.py:472-496`](../../vith/window_arrangement.py) — `close_buffer` direct call + snapshot/live index mix.

## Impact

Closing the last window of a tab via `:bd`/`:bw` (or `close_editor_buffer` across tabs) can leave an empty tab page that crashes focus cycling or renders an empty split.

## Fix direction

Move the invariant into `TabPage`: `close_active_window` returns whether the tab became empty (or refuses to empty), `cycle_focus` no-ops on empty/singleton. Rewrite `close_buffer`’s tab-removal loop to iterate reversed or track the active tab *object* rather than a numeric index.
