# Trailing-slash directory locations render empty short display names

**Category:** UI / display names · **Area:** `vith/editor_buffer.py`, `vith/editor.py` · **Found at:** Round 18 full-project audit (2026-11-24, `v0.16.5`, hg rev `458:d2d313328875`) · **Fix status:** open

## Summary

When a user opens a directory with a trailing slash (standard shell Tab-completion output, e.g. `vith -p src/ tests/`), `eb.location` retains the trailing `'/'`.

* `EditorBuffer.get_display_name(short=True)` returns `os.path.basename(self.location)`, which evaluates to `''` on any trailing-slash path, producing blank tab captions in `TabsControl` and `[Render:  (...)]` in `LiveRenderController`.[^src-eb]
* `Editor.get_title()` computes `os.path.basename(eb.location) or eb.location`, falling back to the full unshortened path `'vith - /long/path/to/src/'` instead of `'vith - src'`.[^src-ed]

## Evidence

Live probe:

* `ed.load_initial_files(["/tmp/demo/subdir/"])` → `eb.get_display_name(short=True) == ''`.

## Fix Direction

1. Strip trailing separators (`location.rstrip('/\\') or location`) before calling `os.path.basename` in both `EditorBuffer.get_display_name(short=True)` and `Editor.get_title()`.
2. Add regression tests covering `'subdir/'`, `'/path/to/subdir/'`, and root `'/'`.
