# `ReportMessageToolbar` shows only `errors[0]` when a line has multiple errors

**Category:** correctness (inherited) · **Area:** `vith/layout.py` · **Found at:** deep review, hg rev 164 (2026-11-06)

## Summary

The message toolbar looks up the error list for the cursor line and displays
only the first entry.

## Evidence

* [`vith/layout.py:282-285`](../../vith/layout.py):
  `errors = eb.report_errors_by_line.get(lineno)` then
  `return errors[0].formatted_text`.

## Impact

A line with several pyflakes findings (e.g. `unused import` + `undefined
name`) surfaces just one; the others are invisible unless the user moves the
cursor column (which doesn't change the lookup) — effectively noise-level UI
loss, but consistent and low-severity.

## Fix direction

Join the per-line errors (multi-fragment join with separators), or cycle
through `errors[n]` on repeated triggers.
