## Impact

None of these crash today; (1)-(3) are why the Thai patch cluster ([064](064.md)) is hard to reason about and regresses.

## Fix direction

Split `thai.py` (behaviour-preserving; keep the import surface stable via re-exports), remove the import-time install, fix the decorator returns, name the `Condition` functions. Keep `__all__` stable during the split.

## Fix record (2026-11-08, hg rev 265)

1. `thai.py` split into `thai_classify` (183 lines), `thai_clusters` (95) and `thai_words` (492) leaves; `thai.py` (912) keeps the patch/renderer core and re-exports the entire public + test-referenced private surface (`__all__` stable). 2. The import-time `install_prompt_toolkit_thai_patches()` call was removed (`Editor.__init__` remains the installer); `tests/conftest.py` installs explicitly and idempotently.
3. `cmd`/`location_cmd` now register the wrapper *and* normalize stacked aliases on the base function via `_unwrap_command` markers; the module-level name keeps the original callable, which intra-module callers (`quit_all` → `quit`) rely on.
4. Both remaining lambdas are named `Condition`s (`tildeop`, `ignore_case`).
5. `super(X, self)` sweep (10 sites) and legacy `class X(object)` gone.
6. `__init__.py` falls back to a single `_FALLBACK_VERSION` constant.
7. `process.py` fetches `_NSGetArgv` once and re-addresses argv[0] via a static cast (previously two syscalls).

1 new decorator-stack test.
