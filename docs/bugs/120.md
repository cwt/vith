# Count before `i` / `a` is ignored

**Category:** Vim semantics · **Area:** `vith/key_bindings.py` (delegated to `prompt_toolkit`) · **Found at:** upstream triage 2026-11-09 (`prompt-toolkit/pyvim#133`) · **Fix status:** open

## Summary

`5itest<Esc>` should produce five copies of `test`; `vith` inserts once.

## Evidence

* `vith/key_bindings.py:146-398`[^src-kb] defines `x/X/s/r/~/e/E/$` with `_positive_count(event.arg)` handling, but has no `i`/`a`/`I`/`A` overrides — insert entry is inherited from `prompt_toolkit`, which drops the prefix count.
* Repro from upstream: normal mode `5ithis is just a test<Enter><Esc>` yields one line instead of five.

## Impact

* Breaks a common Vim idiom for repeated text; workaround is `5o...` or macros.

## Fix direction

* Capture `event.arg` on `i`/`a` entry and replay the inserted region `count` times on `Esc` (or delegate to a repeat register), following the `_positive_count` pattern in [063](063.md).
* Add tests for `5i`, `3a`, and `0`/empty counts.

* [063](063.md) — counted `$` / `e` / `E` overrides.
