# `BufferListOverlay` checks `location in c.display` (`FormattedText` list, always `False`) and triggers on `:buffers`

**Category:** wrong logic · **Area:** `vith/layout.py` (`BufferListOverlay`) · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

`BufferListOverlay` (`vith/layout.py:194-281`)[^src-layout] has two logic defects:

1. **Broken current-completion highlight (`in c.display` vs `in c.display_text`)**:
   In `prompt_toolkit 3.x`, `Completion.display` is a `FormattedText` instance (`[('', 'foo.py')]`), whereas `Completion.display_text` is the plain `str` (`'foo.py'`). Line 255 checks:
   ```python
   info.editor_buffer.location in c.display
   ```
   Testing whether a `str` (`location`) is an element of a list of `(style, text)` tuples always evaluates to `False`. As a result, cycling through `:buffer` Tab completions never marks the selected buffer with `selected = True` in `BufferListOverlay`.
2. **Prefix check matches `:buffers`**:
   `_bufferlist_overlay_visible` (`vith/layout.py:199`) checks:
   ```python
   any(text.startswith(p) for p in ['b ', 'b! ', 'buffer', 'buffer!'])
   ```
   Because `'buffers'.startswith('buffer')` is `True`, typing `:buffers` keeps the floating overlay visible after `'buffer'`, and typing `:bufferfoo` also triggers it (missing trailing space in `'buffer '` / `'buffer! '`).

## Evidence

* [`vith/layout.py:199, 250-258`](../../vith/layout.py)[^src-layout]:
  ```python
  return any(text.startswith(p) for p in ['b ', 'b! ', 'buffer', 'buffer!'])
  ...
  # Does this one match the completion?
  if (
      complete_state
      and complete_state.current_completion
      and info.editor_buffer.location is not None
  ):
      c = complete_state.current_completion
      selected = (
          info.editor_buffer.location in c.display
          or c.text == str(i)
      )
  ```
* **Live probe**:
  ```python
  >>> from prompt_toolkit.completion import Completion
  >>> c = Completion('foo.py')
  >>> c.display
  FormattedText([('', 'foo.py')])
  >>> 'foo.py' in c.display
  False
  >>> 'foo.py' in c.display_text
  True
  ```

## Impact

When completing buffer names via `:b <Tab>`, the currently selected completion is never highlighted in the `BufferListOverlay` popup.

## Fix direction

1. Replace `info.editor_buffer.location in c.display` with `info.editor_buffer.location in c.display_text` at `vith/layout.py:255`.
2. Update the prefix list at `vith/layout.py:199` to `('b ', 'b! ', 'buffer ', 'buffer! ')` (or also match exact `'buffers'`).
