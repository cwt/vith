# Robustness and None-safety inventory (Round 6)

**Category:** robustness / crash-prone paths · **Found at:** Round 6 read-only deep audit, 2026-11-09 · **Fix status:** fixed

## Findings

| # | Location | Issue | Notes |
| :-- | :-- | :-- | :-- |
| 1 | `vith/window_arrangement.py:237-241` | `active_tab` indexes `self.tab_pages[self.active_tab_index]` with no bounds check. | Stale index raises `IndexError`. |
| 2 | `vith/window_arrangement.py:502-552` | `close_buffer()` calls `self.active_tab.close_active_window()` before checking `active_tab is not None`. | Crash on empty arrangement. |
| 3 | `vith/window_arrangement.py:553-561` | `create_tab()` assumes `active_tab_index` is an `int`; `None` raises `TypeError`. | Guard needed. |
| 4 | `vith/window_arrangement.py:562-578` | `list_open_buffers()` dereferences `self.active_tab.visible_editor_buffers()` without a `None` guard. | Crash on empty arrangement. |
| 5 | `vith/window_arrangement.py:418-428` | `_add_editor_buffer()` uses broad `except ValueError: index = 0`. | Masks inconsistent buffer list. |
| 6 | `vith/commands/commands.py:34` | `_confirm_unsaved_changes()` dereferences `active_editor_buffer` without a `None` guard. | Crash on no active buffer. |
| 7 | `vith/commands/handler.py:59` | `_go_to_line()` dereferences `editor.application.current_buffer` without a `None` guard. | Crash on no current buffer. |
| 8 | `vith/commands/completer.py:37-45` | `BufferNameCompleter` yields every buffer when prefix is empty; inconsistent with non-empty prefixes. | Behavior/UX inconsistency. |
| 9 | `vith/completion.py:120-121,126` | Unchecked weakref dereferences may be `None`. | `AttributeError` risk. |
| 10 | `vith/key_bindings.py:83-98,100-116` | `_delete_cell_clusters`/`_replace_cell_clusters` assume `event.arg` is a positive int. | `None`/`0` not guarded. |
| 11 | `vith/lexer.py:169` | `syntax_sync` typed `Any | None` but `.get_sync_start_position` called without a `None` guard. | Crash risk. |
| 12 | `vith/thai/clusters.py:27` | `snap_to_cell_start` does not snap a caller parked exactly at EOL on a combining-heavy line. | Implicit contract. |
| 13 | `vith/thai/patches.py:303-310` | Stray-mark cleanup mutates `new_row` while iterating `new_row.items()`. | Fragile. |
| 14 | `vith/thai/patches.py:611-622` | Autowrap path direct-indexes `screen.zero_width_escapes[y]`. | Crash risk. |

## Fix direction

Add explicit guards and clarify contracts; prefer returning early on `None`/empty state.

## Fix

All 14 items resolved and machine-verified (`pytest`, `mypy .`, `ruff check .`):

1–5. `WindowArrangement` in `vith/window_arrangement.py` bounds-checks `active_tab_index` in `active_tab`, guards `None`/empty states across `close_buffer`, `create_tab`, `list_open_buffers`, `close_tab`, `_split`, `keep_only_current_window`, `show_editor_buffer`, `go_to_next_buffer`, `go_to_next_tab`, and `go_to_previous_tab`, and checks membership explicitly in `_add_editor_buffer`.
6–7. `_confirm_unsaved_changes`, `buffer_edit`, `write`, and `quit` in `vith/commands/commands.py` and `_go_to_line` in `vith/commands/handler.py` guard `None` buffer/tab states.
8. `BufferNameCompleter` in `vith/commands/completer.py` yields prefix matches first and substring matches only when `text` is non-empty, and `BufferListOverlay` in `vith/layout.py` checks `input_params[1] in c.display_text`.
9. `DocumentCompleter.get_completions` in `vith/completion.py` guards expired weakrefs and returns `iter(())`.
10. `_positive_count(arg)` in `vith/key_bindings.py` clamps `None` or non-positive `event.arg` values to `>= 1` across cell-cluster handlers.
11. `DocumentLexer` in `vith/lexer.py` and `ColdTextStack.update_top_cursor` in `vith/cold_text.py` guard `None` / empty states explicitly.
12. `snap_to_cell_start` in `vith/thai/clusters.py` guards `col <= 0 or col >= n or line.isascii()` at entry and documents the EOL preservation contract.
13–14. `vith/thai/patches.py` snapshots `list(new_row.items())` during stray-mark cleanup, guards `screen.zero_width_escapes`, and verifies required parameter names via `_verify_signature` so upstream parameter insertions do not disable patches.
