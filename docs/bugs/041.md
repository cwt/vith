# `WindowArrangement.close_window` (`:hide`) on the last window of a tab leaves an empty `VSplit` and crashes rendering

**Category:** crash / wrong logic · **Area:** `vith/window_arrangement.py`, `vith/commands/commands.py`, `vith/layout.py` · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

`:hide` invokes `editor.window_arrangement.close_window()`, which unconditionally calls `self.active_tab.close_active_window()`[^src-cmd][^src-wa]. When the active tab has only one window, `close_active_window()` deletes that window from `self.root` (leaving an empty `VSplit([])`) and sets `self.active_window = None`. Neither `close_window()` nor `EditorLayout.update()` handles an empty tab, causing immediate crashes in `prompt_toolkit` layout rendering and `TabsControl`.

## Evidence

* [`vith/commands/commands.py:176-181`](../../vith/commands/commands.py)[^src-cmd]:
  ```python
  @cmd('hide')
  def hide(editor):
      """
      Hide the current window.
      """
      editor.window_arrangement.close_window()
  ```
* [`vith/window_arrangement.py:255-263`](../../vith/window_arrangement.py)[^src-wa]:
  ```python
  def close_window(self):
      """
      Close active window of active tab.
      """
      self.active_tab.close_active_window()

      # Clean up buffers.
      self._auto_close_new_empty_buffers()
  ```
* In `TabPage.close_active_window()` (`vith/window_arrangement.py:167-185`), deleting the last window in `self.root` leaves `self.root == VSplit([])` and `self.active_window = None`.
* Immediately after `:hide`:
  * `EditorLayout.update()` (`vith/layout.py:613-625`) builds a `prompt_toolkit.layout.containers.VSplit([])` with zero children, which raises `ValueError: max() arg is an empty sequence` during rendering[^src-layout].
  * If multiple tabs are open, `TabsControl` (`vith/layout.py:84`) accesses `tab.active_window.editor_buffer` and raises `AttributeError: 'NoneType' object has no attribute 'editor_buffer'`.
  * `ReportMessageToolbar` (`vith/layout.py:347-349`) accesses `eb.buffer` on `eb = editor.window_arrangement.active_editor_buffer` (`None`) and raises `AttributeError`.

## Impact

Running `:hide` when a tab has only one window crashes the editor.

## Fix direction

In `WindowArrangement.close_window()`:
* If `self.active_tab.window_count() == 1`:
  * When `len(self.tab_pages) > 1`, close the tab (`self.close_tab()`).
  * When `len(self.tab_pages) == 1`, do not remove the last remaining window ( matching Vim's `E444: Cannot close last window`).
* Guard `ReportMessageToolbar` (`vith/layout.py:347`) when `eb is None`.
