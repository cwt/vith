# Extensionless Python files get no highlighting

**Category:** highlighting · **Area:** `vith/lexer.py` · **Found at:** upstream triage 2026-11-09 (`prompt-toolkit/pyvim#74`) · **Fix status:** fixed

## Summary

`vith example` (Python content, no `.py` suffix) renders as plain text, while `vith example.py` highlights correctly. Vim/atom sniff the content.

## Evidence

* `_ensure_lexer()` in `vith/lexer.py:72-105`[^src-lex] calls only `get_lexer_for_filename()`; on `ClassNotFound` it caches `None` and `lex_document()` at `:107-120` falls back to `SimpleLexer`.
* No shebang (`#!/usr/bin/env python`) or content sniffing (`guess_lexer()`) is attempted.

## Impact

* Scripts without extensions and extensionless executables lose all highlighting.

## Fix

* `vith/lexer.py` adds `_sniff_lexer_for_location()`: on filename-lookup miss, a `python` shebang pins `PythonLexer`, otherwise `pygments.guess_lexer()` sniffs a 4 KiB sample (blank/non-string content keeps the plain-text fallback). Both the streaming and legacy branches use it; the result is cached per location like filename hits.
* Regression tests in `tests/test_lexer.py`: extensionless Python highlighted + cached, shebang pinned, blank stays plain, legacy branch sniffs.
