# Extensionless Python files get no highlighting

**Category:** highlighting · **Area:** `vith/lexer.py` · **Found at:** upstream triage 2026-11-09 (`prompt-toolkit/pyvim#74`) · **Fix status:** open

## Summary

`vith example` (Python content, no `.py` suffix) renders as plain text, while `vith example.py` highlights correctly. Vim/atom sniff the content.

## Evidence

* `_ensure_lexer()` in `vith/lexer.py:72-105`[^src-lex] calls only `get_lexer_for_filename()`; on `ClassNotFound` it caches `None` and `lex_document()` at `:107-120` falls back to `SimpleLexer`.
* No shebang (`#!/usr/bin/env python`) or content sniffing (`guess_lexer()`) is attempted.

## Impact

* Scripts without extensions and extensionless executables lose all highlighting.

## Fix direction

* On `ClassNotFound`, try `pygments.lexers.guess_lexer(text)` (bounded to the first N bytes) and cache per location; keep filename hits fast-path first to avoid perf regressions in [030](030.md) / [065](065.md).
* Add tests: shebang file, `def`-heavy extensionless file, binary guard.

* [030](030.md), [065](065.md) — lexer caching history.
* Upstream: `https://github.com/prompt-toolkit/pyvim/issues/74`.
