# `substitute` (`:s`) raises uncaught `re.error` on invalid regex or replacement escapes

**Category:** crash / wrong logic · **Area:** `vith/commands/commands.py` (`substitute`) · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

`substitute` (`vith/commands/commands.py:726-789`)[^src-sub] has two unhandled edge cases in its regex handling:

1. **Uncaught `re.error` (`re.PatternError`)**: `substitute_in_line` calls `re.sub(search, replace, line, count=sub_count)` directly without catching `re.error`. If the user types a malformed regular expression (e.g. `:s/[unclosed/x`, `:s/*/x`) or an invalid replacement backreference/escape (e.g. `:s/foo/\1`, `:s/foo/\g<bar>`), `re.sub` raises an uncaught `re.error` and terminates the editor.
2. **Empty search pattern with empty search history**: When the user runs `:s//foo` before any `/` search has been performed, `search_state.text` is `""`. Lines 742–743 set `search = search_state.text` (`""`), and `re.sub("", "foo", line, count=1)` matches at index 0 of every line in the range, prepending `"foo"` instead of reporting an error (`No previous regular expression`).

## Evidence

* [`vith/commands/commands.py:732-745`](../../vith/commands/commands.py)[^src-sub]:
  ```python
  def substitute_in_line(line):
      "Substitute synchronously in single line."
      sub_count = 0 if 'g' in flags else 1
      return re.sub(search, replace, line, count=sub_count)

  # Remember search state.
  if search:
      search_state.text = search
  else:
      search = search_state.text
  ```
* **Live probe**:
  * `handle_command(editor, ':s/[unclosed/x')` raises `re.PatternError: unterminated character set at position 0`.
  * `handle_command(editor, ':s/a/\\1')` raises `re.PatternError: invalid group reference 1 at position 1`.
  * On a fresh `Editor` with buffer `"hello"`, `handle_command(editor, ':s//X')` mutates the buffer to `"Xhello"`.

## Impact

A single typo in a `:s` regex or replacement string crashes the editor session, potentially losing unsaved buffer changes.

## Fix direction

1. If `not search` after checking `search_state.text`, call `editor.show_message('No previous regular expression')` and return early.
2. Wrap the `re.compile(search)` / `re.sub(...)` call in `try ... except re.error as e: editor.show_message(f'Invalid regex: {e}'); return`.
