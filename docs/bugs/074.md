## Summary

| # | Location | Cost | Fix |
|---|---|---|---|
| 1 | `editor_buffer.py:87` `buffer.text != _file_content` | Full `O(n)` memcmp per edit (2.4 MB probe file in `bench_plans`) | Dirty-flag/version counter (reuse `ColdTextBuffer._text_version`), reset in `write`/`reload` |
| 2 | `completion.py:63-65` `prefix = text[:line_start]`, `suffix = text[line_end:]` as cache key | Two `O(n)` copies + hash per Tab | Key on `(id(document), row, current_line)` — `Document` is immutable; any edit makes a new object |

| 4 | `completion.py:119` `_jedi_available()` → `find_spec` | Import-system probe per Tab | `functools.lru_cache` (availability is session-constant; mirrors `_JEDI_TAKES_COLUMN` cache) |
| 5 | `commands.py:798,823` `buffer.document.lines` split twice in `substitute` | Two full-text splits per `:s` | Reuse the first `buffer_lines` list |
