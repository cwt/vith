# `variation_selector_always_wide` leaks across `Editor` instances via module globals

**Category:** editor / options · **Area:** `vith/editor.py`, `vith/thai/clusters.py`, `vith/help.py` · **Found at:** Round 18 full-project audit (2026-11-24, `v0.16.5`, hg rev `458:d2d313328875`) · **Fix status:** open

## Summary

`Editor.variation_selector_always_wide`'s setter mutates module-level `variation_selector_always_wide` and `VARIATION_SELECTOR_ALWAYS_WIDE` attributes on `vith.thai.clusters` and `vith.thai`, and its getter returns `True` whenever either module flag is truthy, ignoring `self._variation_selector_always_wide`:[^src-ed][^src-cl]

1. **Cross-instance state leak & corrupted `_default_options`:** Setting `ed1.variation_selector_always_wide = True` causes an independent `ed2.variation_selector_always_wide` to become `True`, and causes a newly constructed `ed3 = Editor()` to snapshot `_default_options['variation_selector_always_wide'] = True` (breaking bare `:set` diffing).
2. **Cannot turn off via `Editor` if only `self._variation_selector_always_wide = False` is set in `__init__`:** `Editor.__init__` sets `self._variation_selector_always_wide = False` directly without clearing module globals.
3. **Missing from `:help`:** `SET_TOGGLE_GROUPS` exposes `variation_selector_always_wide` (`vsaw`), but `HELP_TEXT` in `vith/help.py` omits it from the `Toggles:` list.[^src-help]

## Evidence

Live probe:

```python
ed1 = Editor(...)
ed2 = Editor(...)
ed1.variation_selector_always_wide = True
ed3 = Editor(...)
# ed2.variation_selector_always_wide == True
# ed3._default_options["variation_selector_always_wide"] == True
```

## Fix Direction

1. Have `_vsaw_enabled()` check the active `Application`'s owning `Editor._variation_selector_always_wide` first (via `get_app_or_none()`) and fall back to the module-level flags only when running standalone outside an `Application`, keeping `Editor.variation_selector_always_wide` instance-local.
2. Document `variation_selector_always_wide (vsaw)` in `vith/help.py`.
3. Add a regression test verifying two `Editor` instances keep independent `variation_selector_always_wide` values and factory `_default_options`.
