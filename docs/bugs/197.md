# `:g` whitespace-only args crash

**Category:** commands / global · **Area:** `vith/commands/global_cmd.py` · **Found at:** Round 17 read-only re-audit (2026-11-23, `v0.16.4`) · **Fix status:** open

## Summary

`global_command()` checks `if not global_args` before parsing.[^src-cmd] A whitespace-only argument (`:g   `) is truthy, so it reaches `_parse_global_args()` where `stripped = global_args.lstrip()` is `''` and `stripped[0]` raises `IndexError`.[^src-parse] The empty-string case is guarded upstream; the whitespace-only case is not.

## Evidence

Direct probe against the shipped function (no mocks):

| input | expected | actual |
| :--- | :--- | :--- |
| `'   '` | `E148` / `No previous regular expression` | `IndexError: string index out of range` |
| `' '` | same | `IndexError: string index out of range` |
| `'/foo/d'` | `('foo', 'd')` | `('foo', 'd')` |

Code:

```python
global_args = variables.get('global_args')
if not global_args:          # '   ' is truthy -> passes
    ...
pattern_text, sub_cmd = _parse_global_args(global_args)

def _parse_global_args(global_args: str):
    stripped = global_args.lstrip()
    delim = stripped[0]      # IndexError when stripped == ''
```

## Fix Direction

1. Guard in `_parse_global_args`: `stripped = global_args.lstrip(); if not stripped: return '', ''` (caller already handles empty `pattern_text` via search-state fallback / `E148`).
2. Or tighten caller to `if not (global_args and global_args.strip()):` before parsing.
3. Regression test: `global_command` with `global_args='   '` shows a message instead of raising.
