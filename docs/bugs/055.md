# `substitute` (`:s`) runs `re.sub` twice per line and rebuilds `Document` on zero matches

**Category:** unoptimized algorithm · **Area:** `vith/commands/commands.py` (`substitute`) · **Found at:** deep review, hg rev 191 (2026-11-07)

## Summary

In `substitute` (`vith/commands/commands.py:765-786`)[^src-sub]:
1. Lines 768–770 iterate over `row in line_numbers`, run `substitute_in_line(buffer_lines[row])` (`re.sub`), compare the result with `buffer_lines[row]` to record `last_substituted_row`, and **discard** the substituted string.
2. Line 775 then calls `new_text = buffer.transform_lines(line_numbers, substitute_in_line)`, which runs `substitute_in_line` (`re.sub`) a **second time** on every line in `line_numbers`.
3. Even when `last_substituted_row is None` (zero matches across the range, e.g. `:%s/not_found/x/g`), lines 775–786 still call `buffer.transform_lines(...)`, allocate a new `Document(new_text, ...)`, and assign `buffer.document = doc`. Assigning `buffer.document` fires `on_text_changed`, marking the buffer dirty (`has_unsaved_changes = True`), rescanning the Thai gate, and spawning a background `pyflakes` thread even though nothing changed.

## Evidence

* [`vith/commands/commands.py:765-786`](../../vith/commands/commands.py)[^src-sub]:
  ```python
  # Track the last row that actually changes so the cursor lands on it
  # (or stays put if no line matched).
  buffer_lines = buffer.document.lines
  last_substituted_row = None
  for row in line_numbers:
      if substitute_in_line(buffer_lines[row]) != buffer_lines[row]:
          last_substituted_row = row

  # Apply substitution.
  buffer.save_to_undo_stack()
  new_text = buffer.transform_lines(
      line_numbers,
      substitute_in_line,
  )
  if last_substituted_row is not None:
      cursor_pos = Document(new_text).translate_row_col_to_index(
          last_substituted_row, 0
      )
      doc = Document(new_text, cursor_position=cursor_pos)
  else:
      doc = Document(new_text, cursor_position=buffer.cursor_position)
  buffer.document = doc
  ```
* Notice also that when `last_substituted_row is not None`, `Document(new_text)` is instantiated **twice** (once at line 777 to call `translate_row_col_to_index` and again at line 780).

## Impact

* `:%s/pattern/replacement/g` performs $2\times$ the necessary regex substitutions and allocates two `Document(new_text)` objects.
* `:%s/nonexistent/replacement/g` unnecessarily clones the document, records an undo entry, marks the buffer as having unsaved changes, and triggers `on_text_changed` / `pyflakes`.

## Fix direction

Compile the regex once (`pattern = re.compile(search)`), transform each line in `line_numbers` a single time while tracking `last_substituted_row`, and if `last_substituted_row is None`, report `'Pattern not found'` and return early without touching `undo_stack` or `buffer.document`. When matches occur, construct `Document(new_text)` only once.
